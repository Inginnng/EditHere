# EditHere 网页版

[English](README.en.md)

双击本目录的 **EditHere.html** 即可使用。也可以把这个 HTML 放到普通静态网站，让用户在线打开；页面加载完成后，素材读取、批注、布局调整与导出均在浏览器本地完成。独立 HTML 没有服务端处理、CDN、账号或外部运行时依赖，内容安全策略禁止网络连接。下文的 Agent 会话模式另用本机服务传入图片和取回反馈。

在 Agent 的浏览器侧栏预览时，在项目根目录运行 `node web/preview.cjs`（需要已安装的 Node.js），再打开 `http://127.0.0.1:7330/EditHere.html`。启动脚本会复用本项目的现有服务，或在独立后台进程中启动服务并验证当前 HTML 的响应；服务停止后再次运行即可恢复。“拒绝建立连接”表示本地服务没有监听，刷新页面不能代替启动服务。预览仅监听本机，不上传素材。

## Agent 技能与自动返回

首次安装可直接把 [AI 安装指南](AI-SETUP.md) 和实际的 `web-agent` ZIP 下载地址或本地文件交给 Agent；指南不依赖预先安装 Skill。当前生成的本地包尚不代表已有公开下载入口。

`skills/edithere-web/` 是可安装的 Agent 技能。需要 Node.js ≥ 18，将 Agent Web 包解压到可写且准备长期保留的目录，再运行 `node web/install-skill.cjs`（包内若以本目录为根，则运行 `node install-skill.cjs`）。安装器默认写入 `$CODEX_HOME/skills/edithere-web` 或 `~/.codex/skills/edithere-web`，可用 `--destination <技能目录绝对路径>` 指定其他宿主的技能目录。安装器检查网页与服务文件，并把当前 CLI、Node.js 的绝对路径写入技能的 `references/local-installation.md`；目标已存在就拒绝，不覆盖已有技能，也不修改桌面 `edithere` 技能。保留 CLI 同目录的网页与服务文件，当前服务会在此目录的 `tests/output/` 中生成私有会话和日志。仓库技能保留相对入口，不包含开发者本机路径。网页技能适用于侧栏批注，用户明确指定桌面程序时使用桌面入口。

安装后可以说“帮我用 EditHere 批注游戏主页”，或显式使用 `$edithere-web`。用户给出图片时直接使用；要求批注实际运行页面时，Agent 使用宿主允许的浏览器或窗口截图能力，取得并视检本轮真实截图，再载入右侧会话页面。截图依赖宿主工具，网页连接器本身不包含系统截图实现；不能把目录旧图或固定测试渲染当成当前运行界面。用户点击顶部“反馈”（完成并返回 AI），结果写入本次唯一 JSON 输出，无需手动复制 JSON。

等价的命令行流程（图片和输出均使用实际绝对路径，输出文件需尚不存在）：

```text
node web/agent.cjs start --image <图片路径> --output <新的反馈路径> --timeout 86400
node web/agent.cjs poll --session <start 返回的会话 ID>
```

打开 `start` 回执返回的 URL，而非普通预览 URL。技能保存本次会话记录后交给用户编辑并结束本轮，默认不创建定时任务；用户提交后回到对话说“继续”，Agent 对同一 ID 查询一次。只有本次明确选择定时跟进、宿主支持且满足技能中的关闭检测条件时，才为当前对话注册一次 heartbeat。调度可能显示“由已安排任务发送”，未提交时不输出进度也不能消除宿主的调度消息；注册成功才承诺跟进，并说明延迟。用户明确关闭、取消或可靠工具确认本次页面已关闭时清理关联临时任务，保留原图和会话记录；关闭标签本身没有服务端取消回执，不能仅据 pending 推断页面仍打开。仅在用户明确要求“现在等我提交”时使用单次最多 55 秒的 `wait`。只有 `completed` 且反馈可解析时继续，取消或超时不使用旧结果，并清理已注册的跟进。CLI 本身不会在结束的对话后台代发消息或立即唤醒宿主。本机服务只监听回环地址，图片与反馈不发到外部服务器；普通静态或离线页面继续使用下载/复制方式导出。

## 使用

1. 拖入图片、视频，点击「打开素材」，或粘贴图片。一次编辑一个素材。
2. 图片支持智能选块、点批注、框批注与全局意见。使用「选择」（V）拖动批注点或框，框的八个控制点可调整范围；点击编号编辑文字。
3. 点击「大爆炸」进入组件编辑并播放桌面版同方向的扫光动效；再次点击退出，保留已有位移与批注。选中组件后拖动，八个方向的控制点可调整尺寸；点击全局批注左侧的「组件布局」小按钮，可在浮层中输入位置与尺寸。浮层默认收起，不占批注面板高度。Ctrl / ⌘ + 点击多选组件，整体移动和缩放；指向已选组件滚轮等比缩放，未选中时滚轮切换同一位置不同大小的候选区域。「框出组件」补充未自动识别的区域。移动与缩放显示原位置到目标位置的箭头，点击箭头或对应布局批注添加文字，再次点击可编辑；文字随项目保存，并归入反馈中同一个位移对象。选中组件后可「复位」。
4. 视频播放后暂停，在当前画面批注；点击已标注时间点可以回看。只有实际批注或移动的画面进入导出，不会把每次暂停都保存成一帧。
5. 「导出反馈」下载或复制与桌面 EditHere 兼容的图片 / `video-feedback-1` JSON，默认内嵌原图或批注帧。导出窗口内的「保存批注图」导出带编号和蓝色位移箭头的 PNG。
6. 「保存项目」下载 `.edithere-web.json`，保留原图、批注与组件布局，重新拖入可继续编辑。视频项目包含批注帧，不包含整段视频；重新打开后选择原视频恢复播放。

网页的「下载离线版」提供同一个独立 HTML。关闭页面前保存项目；独立 HTML 不自动写入磁盘，也不把素材保存到服务器或浏览器持久存储。Agent 会话仅在用户明确提交时写入预先指定的反馈输出。

位移在发生时就生成可留空的真实批注，与前后文字批注按建立顺序排列。补写或清空文字不改变编号，保存项目后顺序和编号保留。复位会移除空文字位移批注，已有文字继续保留。这些行为依据桌面版 REG-110 及其原有交互测试。

反馈 JSON 按桌面 `exportFeedback` 的规则导出：真实位移轨迹先建立对象，位移文字归入相同原始 `source`，独立批注使用当前结果区域；空位移的 `annotations` 为 `[]`。父组件的原始轨迹不因子组件脱离而缩窄，再次调整已有组件不重排轨迹。导出预览折叠图片编码、每个图片对象占一行；复制和下载提供完整的紧凑 JSON。侧栏的批注建立顺序与 JSON 的对象分组顺序各自遵循桌面规则。

## 无边界工作台

画布可自由平移和缩放，不受页面滚动边界限制。拖动图片外的空白、使用手形工具（H），或按住空格 / 中键拖动；Ctrl / ⌘ + 滚轮以指针位置为中心缩放。「适应画布」避开浮动工具和批注面板，「1:1」显示原始尺寸。组件布局仍限定在原图范围内，保证桌面反馈坐标兼容。

宽屏使用随内容收缩的右侧浮动意见面板；窄窗口、正方形和竖向窗口采用紧凑底部卡片，原图在上方居中。保存新批注会自动展开并定位到它；多条意见在不超过窗口约四分之一的区域内滚动，避开视频时间轴。收起后，右上角保留批注数量。短横屏使用紧凑工具栏和窄侧面板。坐标保留在批注悬停提示中，精确数值控件按需展开。缩放控件位于顶部中间，小窗口自动排到第二行。编辑工具靠近底边，面板跟随工具高度留出间距。全局批注入口为修改意见标题旁的对话图标。左下角可切换明暗主题并查看快捷键；窄窗口通过左下方「更多工具」菜单访问这些辅助功能。眼睛按钮只隐藏画布标记，不删除批注或改变导出结果。

品牌图标与文字直接复用仓库 `assets/icons/edithere.svg` 及 `assets/brand/edithere-lockup*.svg`；构建时原样内嵌，保持原始比例。明暗主题使用现有对应版本，极窄窗口显示现有图标，示例画布也复用原始组合标识。

## 边界

- 自动分块使用本地色块和边缘算法，未移植桌面版的完整表格层级检测。没选准时可手动框出组件。
- 系统 OCR、全局截图快捷键、长截图、系统托盘和置顶贴图属于桌面能力，本离线 HTML 尚未接入；网页可通过上传或粘贴接收素材。
- 大爆炸移动的是矩形像素区域，原位置留透明空洞；不执行语义抠图、背景补全或视频渲染。
- 图片最多 3200 万像素；视频格式取决于浏览器和系统的解码能力，优先使用 H.264 MP4 或 WebM。支持帧回调的浏览器使用实际呈现帧的媒体时间，其他浏览器回退播放位置；这不是逐帧视频剪辑器。
- 网页项目使用独立格式 `edithere-web-project-1`，暂不支持桌面 `.edithere` 项目。可导入含内嵌图片的当前图片反馈和视频反馈。
- 普通静态/离线页面不能自动读取任意本地路径或向 CLI 返回结果。需要自动返回时，通过上述 Agent 技能创建本机图片会话；其访问范围限于本次传入的图片与输出。
- 在线页面关闭后能否离线重新访问取决于浏览器缓存；下载 HTML 后可以直接断网双击打开。本版未增加 Service Worker。

## 开发与验证

源文件在 `src/`，分块算法复用本仓 `origin/web` 的实现，布局核心依据当前桌面版的像素分区逻辑。生成文件包含全部脚本和样式，不需安装构建依赖：

```text
node web/build.cjs
node --test web/tests/layout.test.cjs web/tests/movement.test.cjs web/tests/feedback.test.cjs web/tests/agent-session.test.cjs web/tests/install-skill.test.cjs
node web/tests/agent-flow.test.cjs
node web/tests/browser.test.cjs
node web/tests/visual.test.cjs
node web/tests/negative.test.cjs
node web/tests/panel.test.cjs
node web/tests/latest-parity.test.cjs
node web/tests/native-video-boundaries.test.cjs
```

浏览器验收脚本 `tests/browser.test.cjs` 使用 Playwright Core；可以通过 `EDITHERE_PLAYWRIGHT_MODULE`、`EDITHERE_BROWSER_PATH` 和 `EDITHERE_TEST_VIDEO` 指定已有安装和测试视频。验收产物位于忽略的 `tests/output/`。新版本修改 `src/` 后必须重新运行构建，以更新交付 HTML。

`agent-flow.test.cjs` 使用 `EDITHERE_TEST_IMAGE` 指定的 PNG（本开发包默认使用已有游戏截图），通过真实 CLI、网页按钮与等待命令验证原图传入、全局 / 点 / 位移文字返回、丢失响应的幂等重试、取消后保留编辑和下载离线版的网络限制。

`visual.test.cjs` 检查六种窗口尺寸的明暗主题、原始品牌文件字节与比例、文字对比度和批注换行，并保存截图。`negative.test.cjs` 在断网浏览器中输入损坏文件、越界坐标、矛盾的位移记录与异常视频帧，检查拒绝操作后原图像素、文字及撤销记录不变；同时覆盖取消替换、取消拖动、空白输入和读取过程中的快捷键。

`panel.test.cjs` 重点检查九种正方形和竖向面板中的短批注占高、原图居中和可见比例、自动展开、批注计数、多条意见滚动、精确数值编辑，以及大爆炸动效、反复开关保留内容和减少动态效果设置。

`latest-parity.test.cjs` 对照桌面已有测试检查位移占位、建立顺序、补字与撤销、空批注项目重载、复位及完整导出数据；`native-video-boundaries.test.cjs` 检查原生空视频反馈、重新关联视频和最后一毫秒内的微秒时间点。所有 JSON 断言读取实际下载文件，预览文字单独验证。

仓库根目录的许可同样适用于此实现。
