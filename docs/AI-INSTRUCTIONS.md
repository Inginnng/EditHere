# AI解析（0.13.0）

[English](AI-INSTRUCTIONS.en.md)

桌面 EditHere 可以把截图、组件移动和批注整理为纯文本修改意见。图片在独立的 API 请求中处理，复制到目标 Agent 对话的内容只含文字，便于控制该对话的上下文占用。识图请求本身仍会消耗提供商的 API 额度。

## 设置一次

1. 打开「设置 → AI 接口」，选择提供商。
2. 填写该提供商普通开放平台的 API Key，点击「保存密钥」。密钥保存在系统凭据库；本页底部的设置保存按钮用于保存提供商选择、模型、地址及高级配置。
3. 点击「测试连接」。测试只发送程序内置的小图，不发送当前截图。成功后保存设置。

预设填好 API 地址、支持图片的模型和接口协议。提供商选项集中显示，API Key、模型和 API 地址直接可见；GLM、Kimi 可切换中国站与全球站。中国站、全球站及 Coding Plan 可能使用不同账号与额度。常规配置可直接编辑；「高级选项」只放接口协议、超时和补充要求，也可选择自定义服务。各平台依据和开源来源见 [提供商预设](ai-providers.md)。内置提示词可在设置页查看；补充要求适合指定输出语言或措辞。

## 生成和交付

1. 批注完成后，直接点击编辑器底部的「AI解析」；「查看 JSON」窗口也保留同名入口。
2. 确认窗口显示的提供商与模型，点击「开始解析」。窗口处理的是打开时的批注快照；仅打开窗口不会发送请求。
3. 核对对象、用户原话、精确数值和「待核对」项，可直接编辑结果。
4. 点击「复制文字」交给 Agent，或「另存为…」导出 UTF-8 TXT / Markdown。

关闭窗口或点击停止会取消仍在进行的请求；请求失败、取消及超时不会自动重试。原图和批注仍在当前项目中。需要持久保存时，另行保存工程。

结果逐条对应批注对象。原始坐标、位移、缩放、视频时间戳和用户原话由程序保留；模型补充对象身份、相邻关系和修改描述。移动对象使用原图坐标，普通批注和子批注使用布局结果坐标，坐标单位为图像像素，不能直接当作 CSS 像素。每个有布局变化的画面同时提供原图与完整分辨率结果图。

编辑器底部「复制 JSON 内容」右侧的「⋯」位于按钮内部，用于选择是否携带原图编码，不再单独占用工具栏位置。

## 当前边界

一次最多处理 100 个对象、8 个视频帧、16 张图片；单张 PNG 最多 5 MiB、整个请求最多 32 MiB。特定提供商还有图片边长限制。超过上限会在本地停止并提示分区或分批处理，不会自动缩图或静默丢帧。模型响应被截断或遗漏对象时不输出一份看似完整的修改清单。

结构和数值校验不能证明模型的视觉判断完全正确。纯文本结果应核对后使用；涉及复杂视觉样式时保留原工程，必要时重新理解相应区域。

API Key 不进入项目、批注 JSON、普通设置文件或诊断日志。QtKeychain 使用 Windows Credential Store、macOS Keychain，或 Linux 桌面提供的密钥服务；系统凭据库不可用时明确报错，不退回明文存储。该功能不会自动读取其他 Agent 工具的密钥或修改其配置。

本版本先实现桌面独立 API 模式，MCP 的宿主独立 Agent 会话模式尚未接入。
