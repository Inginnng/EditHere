## 边界与维护性

- `ParentLink` 合并来源与确认状态，`normalizeNoteParents` 统一处理孤儿、歧义及排序。归属依据组件当前目标位置，完全包含选面积最小的父组件，部分重叠要求确认。旧源位置的空白不会被自动认作子项。
- 自动空父卡与子批注共用撤销事务并计入 1000 条限制；有无空父卡导出等价。删除父卡、归位、确认/否认均覆盖撤销重做；归位后重新移出不会复活已解除的归属。删除全部子项后，空父卡仍表示实际位移，不应自行删除。
- 未确认归属在保存工程时保留，导出前检查所有视频帧，不能通过切换当前帧绕过。
- 反馈中的子框使用结果画布绝对像素坐标，父组件 source 使用原图坐标；Schema 和格式文档已写明。JSON 键序仅用于阅读。
- C++ 与 JS 共享 4 组固定数据；`expected.serializedObjects` 对完整对象树逐字节比较，包括 children 末尾顺序与换行。排除图片字节，避免不同 PNG 编码器造成无关差异。
- 本次修复 Web 通用序列化再次把 children 按字母顺序移到前面的遗漏；预览、复制、下载使用一致规则。
- 同源或像素量化后碰撞的多个组件解除有歧义的父子关联，不任选一个目标。稳定组件 ID 尚未实现；按原审阅允许，留到支持多层嵌套或跨轮关联之前设计，不能把当前矩形键称为永久身份。
- OCR 参数集中，先处理透明底和对比度，再估算文字高度；放大与留白随图片携带统一映射。中文只按词框间距合并紧邻字，保留控件间空格及 Vision 原文。
- 保留实际灰度极值，未直接改用 1%/99% 分位数：稀疏标签的全部文字可能不足 1%，已有用例验证不能把它裁掉。未增加失败后自动扩大裁剪重试。
