This update corrects the AI and command-line documentation and the companion skills shipped with the packages: it documents video projects and has the skill read the program version first.

### Video projects

- The command-line documentation, the connector documentation and the three companion skills now state that the input may be an image, a video or a project. A video project exports `video-feedback-1`, which reuses the existing image feedback structure for each frame, including that frame's timestamp, screenshot and the frame each object belongs to.
- **Apply one batch of annotations once**: reading per frame is enough; the expanded object index must not be applied a second time.
- When the screenshots exceed a tool's per-call attachment limit, read on by frame index; the complete feedback is still saved in the JSON.

### Version check

- The companion skill runs `edithere-cli --version` first and reads the program version, then decides which capabilities are available: image and project annotation needs 0.9.8 or later, and video needs 0.10.0 or later.
- When the version is too low the skill asks the user to upgrade; it does not switch to another program of the same name and does not change the global environment. The version range whose communication endpoint name differs is stated as well.

### Other

- The program itself is functionally the same as 0.10.0; this change is in the documentation and skills shipped alongside it.
- The packages for all three platforms have been rebuilt, and the skill and command-line documentation they carry now match the program's capabilities.

Before upgrading, quit the old version from the tray and save unfinished edits, then run the installer or unpack the new package completely.
