# EditHere 0.14.4

[简体中文](0.14.4.md)

- The pinned image window is rewritten: on scaled displays it no longer looks soft from being downscaled and then blown back up. Double-click closes it, and the first item in its context menu is "Annotate".
- The pin's shadow is now separate from the image used for editing and recognition. Entering annotation or OCR from a pin no longer brings the shadow's extra margin into the canvas, and OCR does not read the glow at the edges.
- Fixed the DeepSeek Harness package silently failing to install its skill when the path contains non-ASCII characters, where the destination stayed empty while the command reported success.

## Features and fixes across the 0.14 series

- The desktop workbench brings screen capture, image sets, and annotation together, with brush, mosaic, and crop tools. Regular and scrolling captures share the same tools.
- AI tools can use the unified CLI and MCP to capture a screen, window, or web page and send the result directly to the annotation workbench.
- The Windows workbench protects unsaved screenshots and annotations when you quit, update, or replace a project. In B2, go to Settings → Diagnostics to check for updates, view progress, or cancel.
- Videos open in the video editor. You can return to B2 to work on screenshots afterward. Automatic capture on startup and the option to create a new annotation in a blank window have been restored.
- Windows packages include the WebView2 Loader, and update checks query public release endpoints directly. The installer waits for desktop and CLI processes in the installation directory to exit and retries when a file is briefly locked.
- Fixed the Skill and unified CLI/MCP resource paths on macOS and Linux.
- Fixed a Windows desktop launch failure in environments managed by nested Job Objects, such as AI IDE terminals.
- Improved diagnostics and automatic fallback when a WebView2 process exits unexpectedly, along with update list pagination and download reliability.
- Consolidated the catalog of 32 AI hosts in `shared/ai-hosts.json` and unified the CLI version source. Completed the Simplified Chinese, Traditional Chinese, and English translations.
- The Chinese interface shows why Skill sync failed. If a write fails, it suggests letting the AI tool update the Skill or refresh its path. The “Installed only” filter is restored after restarting.
- DeepSeek Harness users can download `EditHere-dsh.zip` separately. It includes the image set annotation page, local service, CLI, and `edithere-dsh` Skill.
