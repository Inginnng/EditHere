This update is about two things you meet every day: whether the annotated image you copy stays sharp, and whether the app stays up on macOS. The interface also gains Traditional Chinese.

- **Annotated copies keep their pixels**: wide screenshots are exported at their original size, and the annotation sidebar, text, numbering and spacing scale with the image so they stay aligned ([#42](https://github.com/Inginnng/EditHere/issues/42)). New annotation previews are lossless PNG; JPEG previews saved earlier still open.
- **JSON attachments take the first comment as their name**: the exported JSON and its image are named after the first comment, so a folder of feedback points straight at the problem ([#38](https://github.com/Inginnng/EditHere/issues/38)).
- **Traditional Chinese interface**: the interface language list now offers 繁體中文 next to Simplified Chinese and English, thanks to the contribution in [#43](https://github.com/Inginnng/EditHere/pull/43). With "Follow system", the script your system writes in decides between the two Chinese interfaces.
- **Fix macOS menu bar exits and stray captures**: clicking the menu bar icon no longer closes the app, including keyboard and trackpad events that are not mouse clicks; moving the pointer across the menu no longer starts a capture; and a scrolling capture no longer crashes when a window closes or a page changes while it runs ([#11](https://github.com/Inginnng/EditHere/issues/11), [#41](https://github.com/Inginnng/EditHere/issues/41), [#44](https://github.com/Inginnng/EditHere/issues/44)).
- **Manual scrolling capture no longer reports a false timeout**: when frames arrive slowly during continuous scrolling (a slow machine or a remote desktop, for example), the capture is no longer interrupted by a "capture timed out" notice; a genuinely missing frame callback still reports as before.
- **Stricter local communication and in-app updates**: the desktop app now checks a per-run credential and the operating-system identity of local callers from the CLI and the connector, so another program cannot impersonate them; in-app updates only accept an installer signed by a trusted publisher whose certificate fingerprint matches ([#8](https://github.com/Inginnng/EditHere/issues/8)). No publisher certificate is configured for this version, so checking for updates opens the download page and you install it yourself.
- **Connector 0.2.1**: the connector and its Skills now share one delivery version, and the docs cover reaching a local EditHere from a remote SSH session by passing files back and forth ([#34](https://github.com/Inginnng/EditHere/issues/34)).

The `feedback-minimal-4` feedback format, project format, CLI and Skill contracts are unchanged, and so is installing or updating.

Packages include the Windows installer and portable ZIP, universal macOS DMG, Linux AppImage, offline Web and Web Agent editions. Install or extract the complete package, keeping its runtime libraries and plugins.
