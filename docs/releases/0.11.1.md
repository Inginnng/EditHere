本次更新统一桌面与 Web 的操作图标，让同一功能在不同界面中保持一致，常用操作更容易辨认。

- **一套图标，统一风格**：共用 67 个 SVG 操作图标，61 个采用 Lucide 1.55.0，6 个为 EditHere 自有或改绘图形。线宽、圆角、留白与状态遵循同一规范，品牌图和品牌文字继续沿用现有素材。图标随程序内置，无需联网加载。
- **确认三项专用图形**：长截图使用长画面与上下箭头（`scroll-frame-arrows`），圆角使用平滑连续的大圆角轮廓（`corner-one-large`），大爆炸使用组件拆出的图形（`explode-blocks`）。
- **裁去图标保持对称**：上、下、左、右四个方向采用配对的断线与圆弧，间距和旋转关系一致，修复原先自动虚线造成的不对称。
- **不同操作更容易区分**：项目、图片、JSON 文件、JSON 内容和反馈目录分别使用对应图形；添加批注、放大、撤销、恢复默认、应用设置和组件布局也明确区分。
- **图标与实际状态一致**：新图片载入后同步批注显隐图标与提示；长截图停止后恢复四向移动指示。统一浅色、深色、选中和禁用状态，固定深色截图工具条保留清晰的浅色图标。
- 保留独立 HTML 图标方案页，可查看实际按钮尺寸、明暗效果、功能对应关系与备选方案。

Windows 已在本地完成构建和共享图标测试，包含 54 组裁去图标对称与旋转回归。macOS、Linux 使用同一份共享图标源，本轮尚未在这两个系统上构建；各平台包的交付状态以实际分发文件为准。
