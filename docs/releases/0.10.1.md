本次更新修正随包交付的 AI 与命令行文档、配套 skill：补充视频项目的说明，并让 skill 先核对程序版本。

### 视频项目说明

- 命令行文档、连接器文档与三份配套 skill 写明输入可以是图片、视频或项目。视频项目导出 `video-feedback-1`，每帧复用现有图片反馈结构，包含画面时间、帧截图与对象所属帧。
- **同一批批注只执行一次**：按帧读取一次即可，不需要再对展开的对象索引重复执行。
- 截图超过工具单次附图上限时，按帧索引继续读取，完整反馈仍保存在 JSON 中。

### 版本检查

- 配套 skill 先运行 `edithere-cli --version` 读取程序版本，据此判断可用能力：只做图片与项目标注需要 0.9.8 及以上，涉及视频需要 0.10.0 及以上。
- 版本不足时提示升级，不改用另一份同名程序，也不改动全局环境；通信端点名不一致的版本范围同样写明。

### 其他

- 程序功能与 0.10.0 相同，本次变更集中在随包交付的文档与 skill。
- 三个平台的安装包重新构建，包内附带的 skill 与命令行文档同程序能力对齐。

升级前先从托盘正常退出旧版并保存未完成的编辑，再运行安装器或完整解压新包。
