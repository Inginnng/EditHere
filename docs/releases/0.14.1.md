# EditHere 0.14.1

- **原生高速截图与选窗口直达**：新增 `edithere-cli windows` 与 `capture --output / --annotate`（支持 `--screen`、`--window`、`--window-id`），Windows 采用 `PW_RENDERFULLCONTENT` 抗遮挡离屏采集与 GDI 黑帧兜底，自动排除自身窗口并对多窗口歧义/最小化窗口做安全拒绝，未保存修改保护同步覆盖 Qt 与 B2 编辑器。
- **Web 批注截图提速**：`capture-web.mjs` 告别固定 5 秒 `networkidle` 盲等，基于关键资源请求静默窗口（`300ms` 封顶 `1500ms`）与双 `rAF` 智能判定就绪，忽略 SSE / WebSocket / HMR 长连接，支持多页并发与同视口上下文复用。
- **单调用 AI 截图快路径**：统一 MCP（`cli/unified-mcp.mjs`）与连接器（`0.2.2`）新增 `edithere_capture`（自动分配输出路径并支持屏幕/窗口/网页路由）与 `edithere_windows`，增加桌面 CLI 探测缓存与 60 秒自动回收的温浏览器池。
- **连接起步更轻快**：IPC 起步探测切换为 `15ms -> 25ms -> 40ms -> 60ms` 渐进退避，`Esc` 或抓屏失败取消严格返回取消码并防止状态卡死。
