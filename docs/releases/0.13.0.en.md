In development; not released yet. The desktop app gains an optional **Generate instructions** feature. A separate API request interprets screenshots and annotations; after review, hand only the plain text to the target agent to reduce image context in that conversation.

- **Set up once:** Settings → AI API supplies OpenAI, Claude, DeepSeek, GLM, Kimi and custom-service presets, including base addresses, vision models and protocols, with separate China and global entries. Use your own API key and credits.
- **Generate and review:** open the editor's More menu or View JSON, then edit, copy or save the result. The app preserves original comments, exact coordinates, movement, scaling and video timestamps, and reports missing objects, truncated responses and oversized input.
- **Keys and sources:** reuse QtKeychain's system credential storage and provider configuration based on the MIT-licensed CC Switch, with sources and licences included. Test the connection using only a built-in small image, view the built-in prompt, and add instructions.

Generation sends this task's images and annotations to the selected API provider and uses that provider's credits. Review the model's visual interpretation. This version connects the desktop API mode; the MCP mode using an independent host-agent conversation is not connected yet.
