0.13.0 adds project image-set reviews and optional AI interpretation, with fixes for capture selection, the magnifier, and Windows installation and updates.

- **AI-maintained project reviews**: desktop, Web, MCP Apps, connector, Trae and DSH skills collect accessible pages, preserve stable page IDs, receive annotations, edit source code and replace only screenshots that need refreshing. Continue the next review round in the same set.
- **Relevant pages only**: feedback attaches annotated pages only. AI interpretation sends changed pages with their original and result images, batches large requests by page, and attaches no images for set-wide text comments.
- **AI interpretation (Preview)**: turn screenshots, annotations and geometry changes into text another agent can execute without seeing images. Open it from the editor toolbar or JSON preview. Provider selection persists, the system prompt is directly editable, and cancellation or a trip through settings preserves the draft. Review the result before using it.
- **API settings**: presets for OpenAI, Claude, DeepSeek, GLM, Kimi and compatible custom services. Keys are stored in the system credential store. Requests use your own quota and send images and text to the selected provider.
- **Capture fixes**: settled selections follow continuous dragging without bouncing and retain their size at screen edges. The magnifier displays original pixels without the selection mask, outline or handles, including on scaled displays.
- **Windows IPC hardening**: validate token buffers, SID bounds and integrity levels consistently while retaining elevation, user and integrity isolation. Regressions cover the report in #58; the reporter's device still needs retesting.
- **Clipboard compatibility**: “Copy annotated image” offers lossless PNG bytes and the native image format. Help explains separate text/image pastes for clients that accept only JSON from a file list; the image action is also available from “More” when hidden. Single-paste multi-file support still depends on the receiving client.
- **macOS appearance**: native window controls with corrected title-row alignment, a rounded app icon for Dock/Finder, and a vector template status icon that follows menu-bar appearance. Missing screen-recording permission no longer interrupts startup; manual capture still explains the permission needed.
- **Installation and updates**: fix empty handoff arguments preventing standalone installation. In-app updates retry transient download failures up to twice, retaining signature, hash and transaction checks. Releases become public only after all uploaded draft assets have been verified.
- **Lossless exports**: Web Agent annotated previews now use PNG filenames matching their bytes. Original images, previews and copied images retain lossless pixels.

Screen recording, mosaic/blur redaction and stable Linux ARM64 packages are not included. The project update signature authenticates in-app updates; it is not a publicly trusted Windows code-signing certificate, so first-run system prompts may still appear.
