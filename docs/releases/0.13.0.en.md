In development; not released yet. The desktop app gains an optional **AI analysis** feature. A separate API request interprets screenshots and annotations; after review, hand only the plain text to the target agent to reduce image context in that conversation. The same version adds a DSH image-set entry that collects several screens for annotation and hands them to the AI in DeepSeek Harness at once.

- **Image sets for DSH:** put screenshots of a game, desktop app or website (home, settings, HUD and so on) into one local set, annotate page by page, then choose Finish and return to AI. Only pages with annotations go out, as one JSON file plus the annotated images; unannotated pages keep just a name and size in the index.
- **Three ways in:** drag, paste or multi-select images, grab a page straight from the browser, or drop files saved by any screenshot tool into the inbox directory; on Windows the command line can also capture a window or several displays.
- **One workflow everywhere:** the desktop app, `web/EditHere.html`, `web/EditHere.mcp.html` and DSH share page order, renaming, whole-set comments and result review, so switching entries needs no relearning.
- **Set up once:** Settings now uses a left navigation sidebar. AI API provides OpenAI, Claude, DeepSeek, GLM, Kimi and custom-service presets through a selector with brand icons. The API key, model and address are visible directly, with one Save settings action for both keys and configuration. GLM and Kimi have region selectors. Advanced settings contain only the protocol, timeout and additional instructions. Use your own API key and credits.
- **Generate and edit:** open AI analysis from the bottom toolbar or View JSON. Compare images and original annotations on the left; edit, copy or export instructions on the right, with additional instructions for each run. Regeneration, cancellation and a trip to API settings preserve your draft. The AI translates positions, dragging and resizing into identifiable objects and intended layout relationships, including changes with no written comment. The receiving agent can work from text alone: what to change, where to place it relative to other elements, how to align it and how spacing or size should change. Raw geometry and image metadata are not appended to the result.
- **Independent development:** widgets, prompts, theme, provider presets, API transport and formatting live in [`features/ai-text/`](../../features/ai-text/README.md). A standalone workbench uses the same code, with local response replay, editable fixtures and optional live API access.
- **Bottom toolbar:** AI analysis matches its neighboring buttons and is visible by default. The ⋯ menu is inside Copy JSON content, without a separate toolbar slot.
- **Keys and sources:** reuse QtKeychain's system credential storage and provider configuration based on the MIT-licensed CC Switch, with sources and licences included. Test the connection using only a built-in small image, edit the system prompt by hand, and add instructions. **System prompt** opens the prompt currently in use for direct editing or a one-click restore, applied on the next analysis after settings are saved.
- **Preview label:** both the AI analysis window and the Settings page mark the feature as a preview. Review the result yourself before handing it to an agent; when the model is wrong, the screenshots and annotations win.

Generation sends this task's images and annotations to the selected API provider and uses that provider's credits. Review the model's visual interpretation. This version connects the desktop API mode; the MCP mode using an independent host-agent conversation is not connected yet.
