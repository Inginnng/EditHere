- **Set up once:** Settings → AI API supplies OpenAI, Claude, DeepSeek, GLM, Kimi and custom-service presets, including base addresses, vision models and protocols. Provider choices are grouped together; the API key, model and API address are visible directly, with region selectors for GLM and Kimi. Advanced settings contain only the protocol, timeout and additional instructions. Use your own API key and credits.
- **Generate and review:** open AI analysis directly from the editor's bottom toolbar or View JSON, then edit, copy or save the result. The app preserves original comments, exact coordinates, movement, scaling and video timestamps, and reports missing objects, truncated responses and oversized input.
- **Bottom toolbar:** AI analysis matches its neighboring buttons and is visible by default. The ⋯ menu is inside Copy JSON content, without a separate toolbar slot.
- **Keys and sources:** reuse QtKeychain's system credential storage and provider configuration based on the MIT-licensed CC Switch, with sources and licences included. Test the connection using only a built-in small image, view the built-in prompt, and add instructions.
