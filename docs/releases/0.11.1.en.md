This update unifies action icons across desktop and Web interfaces so the same function is easier to recognize wherever it appears.

- **One consistent icon set**: 67 shared SVG action icons, including 61 from Lucide 1.55.0 and 6 original or adapted EditHere designs. Stroke width, rounded geometry, spacing and states follow the same specification. Existing brand artwork and lettering are retained. Icons are bundled with the application and do not require network access.
- **Three confirmed designs**: scrolling capture uses a tall frame with vertical arrows (`scroll-frame-arrows`); rounded corners use a smooth continuous contour (`corner-one-large`); Explode uses a component separating from a group (`explode-blocks`).
- **Symmetric trim icons**: the top, bottom, left and right variants use paired broken lines and arcs with consistent spacing and rotation. This fixes the asymmetry caused by automatic dash placement.
- **Clearer action meanings**: projects, images, JSON files, JSON text and feedback folders have their own symbols. Adding annotations, zooming, undoing, resetting, application settings and component layout are also distinct.
- **Icons match the actual state**: loading an image resets annotation visibility icons and labels together; stopping scrolling capture restores the four-direction movement indicator. Light, dark, selected and disabled states are consistent, while fixed dark capture toolbars retain readable light icons.
- The standalone HTML icon review page remains available for comparing actual button sizes, light and dark backgrounds, function mappings and alternatives.
- **Web packages on the release page**: this release also ships `EditHere-web.zip` (offline single-file web edition) and `EditHere-web-agent.zip` (for annotation inside Agent hosts; requires Node.js 20+).
