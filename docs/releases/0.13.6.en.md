0.13.6 improves the Windows editor’s window controls and makes the save prompt visible when starting a new annotation from a minimized window.

- **Keep the taskbar visible when maximized (#77).** The Windows editor’s top-right window control now maximizes or restores the window. Press `F11` for full screen or `Esc` to exit it.
- **Restore the editor before prompting to save (#78).** Pressing `Alt + Shift + 1` while minimized restores the editor, then offers to save, discard, or cancel if there are unsaved changes. Cancel keeps your current image and annotations.
