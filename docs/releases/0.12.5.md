本次更新集中在两件日常的事：复制出去的批注图是否清楚，以及在 macOS 上程序是否稳。界面同时加入繁體中文。

- **复制带批注的图片不再被压缩**：宽图按原始像素导出，左侧批注栏、字号、编号与间距随原图同比例放大，放大后仍与原图对齐（[#42](https://github.com/Inginnng/EditHere/issues/42)）。新生成的标注预览改用无损 PNG，此前保存的 JPEG 预览仍可正常打开。
- **JSON 附件按第一条批注命名**：导出的 JSON 与配套图片以第一条批注意见作为文件名，在文件夹里一眼就能找到对应的问题（[#38](https://github.com/Inginnng/EditHere/issues/38)）。
- **新增繁體中文界面**：界面语言在简体中文、English 之外增加繁體中文，感谢 [#43](https://github.com/Inginnng/EditHere/pull/43) 的贡献。选择「跟随系统」时，按系统使用的汉字字形自动选择简繁体。
- **修复 macOS 菜单栏相关的退出与误触**：点击菜单栏图标（包括键盘、触控板等非鼠标事件）不再退出；鼠标滑过菜单时不再误触截图；长截图过程中关闭窗口或切换页面导致的闪退也已修复（[#11](https://github.com/Inginnng/EditHere/issues/11)、[#41](https://github.com/Inginnng/EditHere/issues/41)、[#44](https://github.com/Inginnng/EditHere/issues/44)）。
- **本地通信与程序内更新更严格**：桌面程序与命令行、连接器之间的本地通信增加每轮随机凭据与操作系统身份核验，其他程序无法冒充调用；程序内更新只接受可信发布者签名、且证书指纹匹配的安装包（[#8](https://github.com/Inginnng/EditHere/issues/8)）。当前版本尚未配置发布者证书，因此在程序内检查到新版本时会打开下载页，由你手动下载安装。
- **连接器更新到 0.2.1**：连接器与配套 Skills 的交付标识统一；补充在远程 SSH 环境中通过文件往返使用本地 EditHere 的步骤（[#34](https://github.com/Inginnng/EditHere/issues/34)）。

反馈格式 `feedback-minimal-4`、工程格式与 CLI、Skill 契约保持不变，安装与更新方式也不变。

提供 Windows 安装器与免安装 ZIP、macOS 通用 DMG、Linux AppImage，以及离线 Web 与 Web Agent 包。请完整安装或解压，保留随包运行库及插件。
