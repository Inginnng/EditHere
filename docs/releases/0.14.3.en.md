# EditHere 0.14.3

[简体中文](0.14.3.md)

- The desktop workbench brings screenshots, image sets, and annotations together, with brush, mosaic, and crop tools. Standard and scrolling captures share the same toolbar.
- AI tools can use the unified CLI and MCP to capture a screen, window, or web page and send the result to the annotation workbench.
- The Windows workbench protects unsaved screenshots and annotations when quitting, updating, or replacing a project. Check for updates, view progress, and cancel from B2 Settings → Diagnostics.
- Opening a video uses the video editor and leaves B2 available for screenshots. Capture on startup and creating an empty annotation workspace work again.
- The Windows package ships the WebView2 Loader, and update checks use public release APIs directly. The installer waits for the desktop and CLI in the selected installation and retries brief file-sharing conflicts.
- Fixed the packaged Skill and unified CLI/MCP paths on macOS and Linux.
- Restored the classic `v0.13.7` app icon and EditHere wordmark, including the classic icon for Windows executables and the installer.
- Fixed automatic launch of the Windows desktop app from environments that use nested Job Objects, such as AI IDE terminals.
- Improved diagnostics and automatic fallback when a WebView2 process exits unexpectedly, as well as update list pagination and download reliability.
- Consolidated the 32 AI host entries in `shared/ai-hosts.json`, unified the CLI version source, and filled in missing Simplified Chinese, Traditional Chinese, and English translations.
- Skill sync errors follow the interface language. For write failures, EditHere suggests updating the skill or refreshing its paths through the AI tool. The installed-only filter is remembered after restart.
- DeepSeek Harness users can download `EditHere-dsh.zip` separately. It includes the image-set editor, local service, CLI, and `edithere-dsh` skill.
