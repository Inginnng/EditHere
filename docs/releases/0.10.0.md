本次更新新增视频批注、长截图功能，同时修复若干稳定性问题。

### 视频标注

- 打开或拖入视频即可播放，内置播放与音频、时间轴、前后定位一秒；暂停后沿用现有的点、框、文字与组件调整工具，在目标画面写下修改意见。
- 时间轴上已标注的画面用青色下尖标签标出，尖端指向进度条；悬停放大，点击回到对应画面与批注，「已标注画面」列表同样可以跳转。
- 播放画面与标注画布共用同一显示区域；播放、暂停按钮采用一致的背景，控件保留稳定宽度，切换状态不再挤动时间轴与附近按钮。
- 保存 `.edithere` 视频项目只引用源视频地址，保存已标注帧的截图与编辑状态；源视频移动或丢失后仍可查看保存的截图，并可重新指定视频恢复播放。
- 导出 `video-feedback-1` JSON，每帧复用现有图片反馈结构，包含实际画面时间戳与截图，展开的图形对象附 `timestampMs` 与 `frameId`；同一坐标在不同时间点的意见分别保留。
- 命令行工具与 MCP 连接器支持视频会话与项目导出；截图超过工具单次附图上限时，明确列出继续读取的帧索引，完整反馈仍保存在 JSON 中。

### 长截图

- 框选可滚动区域后点击工具条的「长截图」或按 `L` 开始；选区外为半透明灰色遮罩，空心边框标出实际采集范围，紧凑工具栏位于选区下方。
- 支持上下双向采集，往返已截取的内容不重复拼接；右侧预览保持固定宽度并向两端延伸，绿色框标出当前画面位置，超出屏幕后显示当前位置附近的原图区域。
- 运行时拖动移动手柄沿采集方向移动选区，保留现有长图并继续追加；停止后可自由移动、拖动边缘调整大小。切换垂直与水平方向或实际改变选区尺寸会从当前画面重新开始一轮。
- 剪刀菜单可即时裁掉当前画面上、下边界以外的像素，横向模式为左、右；反向滚动时可开启自动裁剪。编辑、复制、保存与贴图均使用裁剪后的原图。
- 新增长截图设置：默认方向、自动裁剪与超长截图模式可在设置中修改；保存使用普通对话框选择位置。
- 可选「超长截图」模式单轴最长 200 万像素，超出编辑器图像上限的结果以分块 PNG 保存；超过 32767 像素边长或 3200 万像素后仍可保存 PNG，但不能直接编辑、复制或贴图。
- 新增 macOS ScreenCaptureKit、Linux X11 和 Wayland Portal/PipeWire 采集后端，共用同一套预览、菜单与拼接功能。macOS 自动滚动需要辅助功能及事件投递权限，X11 需要 XTEST；Wayland 当前支持手动滚动。

### 诊断日志

- 设置新增「诊断日志」，可打开本机日志目录或导出一份文本报告反馈问题。独立 QtCore 模块记录运行环境、操作状态和错误，自动轮换日志，不采集截图或批注正文，也不会自动上传。

### 修复

- 修复长截图准备时切换方向导致采集退出、普通截图旧回调影响新会话，以及贴图批注覆盖未保存内容的问题。
- 修复切换视频后后台旧画面再次出现、视频预览时状态接口漏报未保存修改，以及拖入异常图片可能导致程序退出的问题。
- 修复长截图一开始滚动就提示「无法匹配相邻画面」的问题：手动滚动时边滚边拼，右侧实时显示已拼接的整张长图；滚得太快对不上时提示稍微往回滚动。
- 修复视频暂停后批注卡顿、框画上却不显示的问题；时间轴上的批注标记可以点击，直接回到对应画面与批注。
- 修复反馈中同中心缩放丢失、相近小数坐标被合并，以及多次移动后批注位置不一致的问题。
- 修复文字识别辅助程序启动失败后持续忙碌、复用识别窗口仍显示旧图片，以及历史截图被旧异步检测结果覆盖的问题。
- 保存截图样式时保留边框与阴影颜色及透明度。
- 反馈导入提前检查异常坐标与累计数量，并限制重叠区域重建时的临时内存。
- 桌面通信清理超长与空闲请求，正确接收分片中文路径；MCP 连接器保留分块输出中的中文，正确报告异常退出与超时。

### 平台与验证

- Windows 完整回归 24/24 组通过，并验证真实外部窗口的长截图全流程。Ubuntu 24.04 完整回归 23/23 组通过，X11 后端在 Xvfb 中验证原生像素、滚轮、1 倍/1.5 倍/2 倍缩放及缺少 XTEST 时的手动采集。
- Wayland 授权会话及像素映射测试 16/16 项通过，PipeWire 原生客户端已编译并完成运行时初始化验证；尚未在真实 Wayland 桌面验收。macOS 实现已补齐，并在 macOS 构建中编译通过，尚未在 Mac 实机验收。视频播放所需的解码库随程序包分发；文字识别使用系统已安装的识别能力，不联网、不上传。
- 长截图专项覆盖超长 200 万像素拼接与分块 PNG 导出，并由独立解码逐像素核对。
- 升级前先从托盘正常退出旧版并保存未完成的编辑，再运行安装器或完整解压新包。

完整操作与数据说明见仓库的 `docs/VIDEO-ANNOTATION.md` 与 `docs/LONG-CAPTURE.md`。
