**0.10.0 本地测试说明：尚未公开发布，当前 GitHub 最新下载入口尚未切换到本版。**

本次更新新增视频按时间批注：在视频里暂停到目标画面，圈选或点选后写下修改意见，再把多个时间点的截图、坐标与批注一次交给 AI。播放控件也改为稳定的布局，定位画面时不再来回挤动按钮和时间轴。

### 视频标注

- 打开或拖入视频，内置播放与音频、时间轴、前后定位一秒；暂停后沿用现有点、框、文字与组件调整工具。
- 时间轴用橙色标记显示已标注画面，下拉列表可直接回到对应时间点，继续查看或编辑。
- 保存 `.edithere` 视频项目时只引用源视频地址，保存已标注帧的截图与编辑状态。源文件移动或丢失后仍能查看这些截图，并可重新指定视频恢复播放。
- 导出 `video-feedback-1` JSON，每帧复用现有图片反馈结构，包含实际画面时间戳和截图；展开的图形对象直接附上 `timestampMs` 与 `frameId`。同一位置在不同时间点的意见分别保留。
- CLI 和 MCP 连接器支持视频会话与项目导出。截图超过工具单次附图限制时，明确列出继续读取的帧索引，完整反馈仍保存在 JSON 中。

### 播放与定位

- 播放、暂停按钮使用一致的背景；按钮、时间显示和已标注画面列表都保留稳定宽度，切换状态不再挤动附近控件。
- 播放视频与暂停批注使用同一显示区域；前后定位一秒和拖动时间轴在后台定位，停在目标画面供批注。暂停中定位保持暂停，播放中定位后也暂停；再次点击“播放”或按空格继续播放。连续点击会按待定位目标累计步进。
- 同分辨率的换帧保留缩放、平移、标注工具和侧栏状态，批注输入不会被强制窗口激活和焦点切换打断；快速步进时减少重复的分块分析。
- 保存、复制与提交使用实际截获画面的时间戳，避免将旧画面关联到新的进度时间。

### 稳定性修复

- Windows 长截图支持实时预览、完成、停止和返回选区，识别固定顶底栏并按可信重叠拼接；默认手动滚动、自动拼接。
- 长截图的状态提示不再改变工具栏按钮位置，避免再次点击时误触保存图片。
- 修复布局变化和批注位置的导出恢复、通信中的分片中文路径、OCR 辅助进程及截图样式保存等问题。
- MCP 连接器保留分块输出中的中文，准确报告异常退出与超时，并在宿主断开时结束等待中的 CLI。

### 验证与使用

- 使用宣传视频完成真实播放、暂停标注、项目保存恢复、CLI 会话及多帧 JSON 测试。
- 独立 AI 读取两张截图中的三条反馈，准确定位三处修改及源动画工程中的文字样式、标签和照片资产；精确时间与源视频 PTS 对应，本次无需更换 JSON 格式。
- 本轮视频功能实机验收为 Windows；macOS 与 Linux 的视频行为以各自构建和验证结果为准。视频播放的插件与解码库随程序包分发。
