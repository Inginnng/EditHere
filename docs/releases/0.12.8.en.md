Windows installed and portable builds support free project update signatures. After verification, choose “Update now” in Settings → About and updates. Download integrity checks, unsaved-edit confirmation, installer readiness handoff and failure recovery remain in place.

**Versions 0.12.7 and earlier need one manual installer upgrade from this repository’s release page.** Older clients do not contain the new trust key and cannot authenticate the first migration; the upgraded client can authenticate later signed updates. A release without a matching signature or compatible installer remains available through the manual release-page download.

Project signatures authenticate project update packages; they are not publicly trusted Windows code-signing certificates. Unknown Publisher and SmartScreen warnings may remain. No system security checks need to be disabled.
