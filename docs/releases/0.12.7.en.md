### Configure tray single and double clicks

In **Settings → Default behavior → Tray icon**, choose separate single- and double-click actions: Capture, New annotation (empty window), Show current window, Open image or project, and Do nothing. By default, **single click captures and double click opens an empty window**.

Single clicks wait for the system double-click interval; a double click cancels the pending single click. Right-click menu actions and shortcuts respond immediately. Save applies changes immediately and keeps them across restarts; Cancel discards them. Showing the window preserves the current document, and opening an empty window retains the existing unsaved-edit, AI-session, capture and modal-dialog safeguards. The Default behavior page scrolls and supports Simplified Chinese, English and Traditional Chinese.

**Platforms:** Windows supports both click settings. Linux double-click support depends on the desktop tray delivering the event. macOS retains its native status bar menu and does not currently support custom single or double clicks; both controls are disabled with an explanation. Use menu actions or shortcuts on macOS.
