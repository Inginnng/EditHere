# EditHere 0.14.4

[English](0.14.4.en.md)

- 重写置顶图片窗口：缩放屏幕上不再因为先把图缩小再放大而发虚；双击关闭，右键菜单首项为「批注」，点它直接进入编辑。
- 置顶图的阴影与编辑、识别用的图像分开。从置顶图进入批注或文字识别时，画布不再多出阴影外扩的那一圈，识别也不会读到光晕边缘。
- 修复 DeepSeek Harness 独立包在含中文的目录下安装 Skill 时静默失败、目标目录为空却报告成功的问题。

## 0.14 系列功能与修复

- 桌面工作台统一了截图、组图和批注操作，提供画笔、马赛克和裁剪工具。截图与长截图使用同一套工具。
- AI 工具可通过统一 CLI 和 MCP 直接截取屏幕、窗口或网页，并将截图送入批注工作台。
- Windows 工作台在退出、更新或替换项目时保护未保存的截图和批注。更新检查、进度和取消均可在 B2 的「设置 → 诊断」中使用。
- 打开视频会使用视频编辑器，之后仍可回到 B2 处理截图。恢复启动自动截图和「新建批注（空窗口）」。
- Windows 发行包随附 WebView2 Loader，更新检查直接访问公开的发布接口。安装器等待同目录的桌面与 CLI 进程退出，并对短时文件占用重试。
- 修正 macOS 与 Linux 的 Skill 和统一 CLI/MCP 资源路径。
- 修复从 AI IDE 终端等受嵌套 Job Object 管理的环境自动唤起 Windows 桌面端失败的问题。
- 增强 WebView2 进程异常退出时的诊断与自动降级保护，改进更新列表分页和下载稳定性。
- 统一 32 个 AI 宿主的清单（`shared/ai-hosts.json`）和 CLI 版本来源，补齐简体中文、繁体中文和英文翻译。
- 中文界面会显示 Skill 同步失败的原因。遇到写入问题时，提示可由 AI 工具自行更新 Skill 或刷新路径。「仅已安装」筛选会在重启后恢复。
- DeepSeek Harness 用户可以单独下载 `EditHere-dsh.zip`，内含组图批注页面、本机服务、CLI 和 `edithere-dsh` Skill。
