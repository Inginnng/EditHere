### 截图流程：选区确认与工具条

- **松开鼠标后进入选区确认**：截图完成后先固定选区，工具条出现在选区旁；批注、复制、贴图、识别、取色等操作均由工具条入口，回车直接进入批注。
- 工具条包含**批注**、**文字识别**、**贴图**、**保存图片**、**复制图像**，以及尺寸、比例、历史与「更多」。
- 选区右侧样式列提供**圆角**、**阴影 / 边框**、**重置**：圆角与阴影通过滑块调整，效果在选区上实时预览；勾选「每次截图都设置」可将当前样式保存为默认值。
- 选区支持后续调整：区域内拖动为移动，拖角为缩放，区域外拖动为重新框选；**方向键移动鼠标指针**（放大镜同步跟随，用于像素级对齐），按住 `Shift` / `Ctrl` 调整对应方向的边。
- 支持锁定 1:1、4:3、3:2、16:9、9:16 等比例（含自定义，如 `21:9`），也支持直接输入精确宽高。
- **取色**：按 `C` 进入，放大镜跟随指针实时读取颜色，支持 `RGB` / `HEX` / `HSV` / `HSL` 四种格式，`Shift` 循环切换；按 `C` 或 `Ctrl+C` 复制颜色值，`Esc` 退出。
- **文字识别**：识别结果逐行列出，单击某行高亮其在图中的位置；支持复制全部或仅复制选中行，也支持切换语言重新识别。使用系统内置识别能力，**不联网、不上传**。
- **贴图（置顶）**：贴图落在**原截图所在位置**而非屏幕居中；支持拖动、滚轮缩放、按 `0` 适应屏幕；右键菜单首项为**批注**，`Ctrl+C` 复制，双击或 `Esc` 关闭，支持同时置顶多张。
- **置顶图激活状态指示**：当前操作的置顶图阴影为**蓝色**，点击其他窗口后转为**灰色**；关闭阴影时不显示任何颜色。
- **圆角、边框与阴影**：三者在选区上所见即所得，复制、保存、贴图、识别输出均为包含上述效果的成品图。阴影默认开启，由「强度」滑块控制（0–100），颜色采用界面强调色。
- 最近 **20 张截图**与 **10 个选区**跨会话保留，按 `H` 可从历史记录中直接打开。

### 置顶图片：边缘缩放、旋转与透明度

- **边缘拖拽缩放**：指针移至图片边缘或四角时显示对应缩放光标，拖拽即可调整尺寸；缩放过程中图片实时跟随，后续滚轮缩放从当前尺寸继续。
- **右键菜单新增**：**旋转**（左 / 右 90°、水平翻转、垂直翻转）、**透明度**（100% / 75% / 50% / 25% / 10%）、**阴影**（随时开关）。
- 置顶图片的边缘由**阴影**标示，不额外描线：关闭阴影后图片不带任何边框，与同色桌面背景融为一体；可拖动的边缘仍然存在，仅不显示。

### 空批注窗口与关闭确认

- 托盘菜单新增**「新建批注（空窗口）」**：打开一个不含图片的批注窗口，无需先截图。窗口中央提示**「可直接拖入或粘贴图片」**，下方为**「导入图片或项目」**按钮：把图片**拖进窗口**、按 `Ctrl + V` 粘贴，或点击按钮从文件里选择，三种方式都能开始批注。
- **托盘菜单精简为**：**截图**、**新建批注（空窗口）**、**打开图片或项目**；移除「恢复批注窗口」与「粘贴图片」两项。
- 关闭批注窗口的保存确认新增**「不再提醒，可在设置中修改」**：勾选后关闭窗口时直接放弃未保存修改，不再弹窗；可在**设置 → 默认**中通过「关闭批注窗口时询问是否保存」重新启用。

### 修复

- 修复截图时整屏发虚：高分屏下整屏画面不再经压缩后重新放大，清晰度与屏幕一致。
- **阴影仅在置顶图片上绘制**：截图窗口不再绘制阴影。
- **放大镜与取色常驻**：选区确认后，指针位于选区内时放大镜与颜色读数持续显示，四种颜色格式随时可读，无需先按 `C`。
- 放大镜放大**屏幕所见内容**（含识别框与暗化区域）；面板更紧凑、倍率更高，并自动避让工具条与样式列。
- 修复方向键失灵或偏移、方向键微调时选中区域缩小、滚轮选定的大区域在鼠标移动后回退为小区域等问题。
- **置顶图片不再绘制边框**：边缘一律由阴影标示，不再在阴影外侧多出一圈实线。
- 修复缺少界面字体的电脑上数字显示为异常符号的问题：界面字体改为在运行时从系统已安装字体中解析，候选字体均缺失时交给系统默认字体，不再按名称直接指定。
- 修复进入截图模式后的卡顿：移除鼠标移动时的重复计算，大选区拖动性能显著提升。
