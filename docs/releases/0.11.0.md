为了降低EditHere的使用难度，同时简化使用方法，本次更新新增了Web版本的EditHere，可以直接在各类IDE侧边呼出，直接进行批注并反馈AI，同时实现了配套skills，适合用于快速使用EditHere功能。但Web版本EditHere尚未完整适配截图，其截图功能存在部分不足，并且依赖于Agent唤起，如需快速截图批注仍推荐桌面程序版本。

- **IDE侧边小面板也能方便批注**：针对IDE侧边浏览器常态化为小面板进行适配，顶栏根据可用宽度收紧，批注编辑与组件布局按需展开，适应近似正方形和纵向面板。
- **在 Agent 中完成反馈**：支持 MCP Apps 的宿主可接收图片、打开批注界面并取回结构化反馈。展开到右侧还是显示在对话中由宿主决定；反馈先保存再回传，通信失败可重试，重新打开可恢复已保存草稿。
- **保存按钮按你的选择工作**：可选保存 JSON 文件、复制 JSON 内容、保存项目或查看 JSON 文件；下拉只切换选择，点击主按钮才执行。文件与复制内容一致，可选择是否附带原图，并查看批注数、位移数与体积。
- **接入更方便**：新增网页版安装指南（`web/AI-SETUP.md`）与本地预览脚本（`web/preview.cjs`）；首次接入把指南和安装包一起交给 Agent 即可。
- 图片反馈保持桌面兼容的 JSON 结构、批注顺序和坐标精度。Web 和 Web Agent 分别打包；桌面与 Web 的入口和平台限制仍以各包说明为准。
