本次补丁修正桌面窗口的双击与跨屏显示行为（[#51](https://github.com/Inginnng/EditHere/issues/51)）。

- **双击标题栏最大化与还原**：双击编辑窗口标题栏或标题文字可最大化，再次双击还原；全屏状态和截图工具栏不切换。
- **拖动窗口优先使用系统处理**：跨显示器移动、缩放切换和窗口吸附交由桌面窗口管理器；不支持系统拖动的平台保留原有拖动方式。
- **Windows 编辑窗口使用完整的不透明背景**：避开透明分层窗口在跨不同缩放显示器移动时可能留下大片透明区域的路径。窗口边角也会绘制背景。

实际双屏、不同缩放比例组合仍需在对应机器复测；自动检查覆盖双击、最大化还原、全屏保护及 Windows 窗口移动和调整大小后的完整绘制。

提供 Windows 安装器与免安装 ZIP、macOS 通用 DMG、Linux AppImage，以及离线 Web 与 Web Agent 包。
