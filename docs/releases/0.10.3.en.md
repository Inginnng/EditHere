This update fixes text recognition for small, narrow captures and the resize cursor on the blue capture selection, and checks both GitHub and Gitee for updates, choosing the update channel that suits the user's network.

- **Text recognition for small images**: fixes narrow images that could not be recognised. They are enlarged before recognition, and the highlight position of recognised text corresponds to the enlarged image.
- **Capture selection cursor**: hovering within the resize area around a blue selection corner immediately shows the resize arrow. The cursor stays consistent during and after dragging.
- Added regression tests for recognition of the small image, scaling limits and coordinates, and cursor behaviour across display scales and selection modes.
- **Two release sources**: checks stable releases on GitHub `Inginnng/EditHere` and [Gitee `InnGing/EditHere`](https://gitee.com/InnGing/EditHere), choosing the newer version by version number.
- **Source failure reports**: if one source fails, the other source's result remains usable and the app reports that the check is incomplete; if both fail, it reports that the update check failed.
- **Integrity verification**: for the same version, a source with a compatible package and its SHA-256 file is preferred. The package and checksum stay with the same source.
- Added regression tests for version selection across both sources and source failures.
