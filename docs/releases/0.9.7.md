### 批注与组件调整

- **移动在发生时即成为批注**：组件调整中挪动一个组件，批注列表同时出现对应的一条，编号与画面上的箭头一致，位置按发生顺序排列，之后补写文字不改变它。
- 移动批注**可以没有文字**，未写文字时同样计入批注条数与导出结果，点开即可补写。
- 组件移回原位后，没有文字的移动批注一并移除；已写过文字的批注保留。

### 反馈导出

- **复制 JSON 文件**：把反馈 JSON 写入临时文件并复制该文件，包含完整原图，适用于可以直接发送文件的 Agent。
- **复制 JSON 内容**：复制反馈 JSON 文本，包含完整原图，适用于只能粘贴文字的 Agent。
- 「查看 JSON」窗口同时提供上述两项，并保留「保存 JSON 与图片」。
- 批注窗口与工具栏新增**「无法使用？」**，列出发送文件被截断、仅支持对话等情形的处理办法。

### 截图与窗口

- 默认截图快捷键改为 `Alt + Shift + 2`；已有设置保持不变，可在设置中修改。
- **截图后恢复此前的窗口**：取消、复制或保存截图后，把前台交还给截图前正在使用的窗口。
- 托盘入口仍然先关闭自身菜单与系统弹层，再采集画面。

### 修复

- 修复移动批注总是排在批注列表末尾的问题：移动批注在发生时建立，可与文字批注交错排列。
- 修复快捷键截图后原窗口失去前台的问题。

### 稳定性

- 发布环节新增安装包自检：任一平台的安装包缺失或为空即中止发布，避免出现只有源码的发布页。
