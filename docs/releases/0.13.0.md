- **组图交给 DSH**：把游戏、桌面程序或网页的首页、设置页、HUD 等多个界面截图放进一个本机组图，逐页圈画、写意见，点「完成并返回 AI」后只把有批注的页面整理成一份 JSON 和对应批注图。未批注的页面只在索引里留下名称和尺寸，不占图片体积。
- **三种投递方式**：拖入、粘贴、多选图片，直接抓取浏览器里的页面，或把截图工具保存的文件放进收件箱目录自动加入；Windows 下还能用命令行截取窗口与多屏。
- **同一条组图流程**：桌面端、`web/EditHere.html`、`web/EditHere.mcp.html` 与 DSH 共用页面顺序、重命名、整组意见和结果审批规则，换入口不用重新学。
- **配置一次**：设置改用左侧导航，AI 接口通过带品牌图标的选择器提供 OpenAI、Claude、DeepSeek、GLM、Kimi 及自定义服务预设。API Key、模型和地址直接可见，底部一次保存密钥与配置；GLM 与 Kimi 提供地区切换。高级设置仅保留协议、超时和补充要求。使用自己的 API Key 与额度。
- **生成与编辑**：直接从编辑器底部「AI解析」或「查看 JSON」进入，左侧同时对照画面与原始批注，右侧编辑、复制或导出修改说明。可填写本次补充要求；重新解析、取消请求、往返 API 设置均保留已有草稿。AI 将像素位置、拖动与缩放转成对象身份和预期布局关系，包括没有文字批注的拖动。目标 Agent 仅凭文字就能理解要改哪个对象、与谁对齐、如何调整间距和大小，结果不附带原始坐标或图像元数据。
- **独立开发**：界面、提示词、主题、服务商配置、API 客户端和结果排版集中在 [`features/ai-text/`](../../features/ai-text/README.md)。独立工作台复用真实代码，提供本地回放与可编辑示例，也可手动连接真实 API。
- **底部工具栏**：「AI解析」与同排按钮样式一致并默认显示；「复制 JSON 内容」的「⋯」收进按钮内部，不再单独占位。
- **密钥与来源**：复用 QtKeychain 的系统凭据库，提供商配置参考 MIT 许可的 CC Switch，来源与许可随包保留。支持只使用内置小图的连接测试、系统提示词手动编辑和补充要求。设置页的「系统提示词」会把当前提示词完整打开，可直接改写或一键恢复默认，保存设置后随下次解析生效。
- **预览标注**：「AI解析」窗口和设置页都标出「预览」，结果需要你自己核对后再交给 Agent；模型判断有误时以画面和批注为准。
- **macOS 窗口控制**：编辑窗口改用系统标题栏，关闭、最小化和缩放是左上角的红绿灯，不再在右上角自绘；窗口四边都可以拖动调整大小，圆角与边框由系统绘制。客户区盖住系统标题栏后 Qt 会加一条清不掉的顶部内容边距，因此编辑器自己的标题栏改为按系统红绿灯的实际行高定位，两者保持在同一行。
- **启动时的录屏权限**：升级或重新打包后 macOS 会让旧的屏幕录制授权失效。启动时若还不能抓屏，程序静默驻留托盘并写诊断，不再弹出「截图未完成」；手动截图时才说明缺哪项权限。
