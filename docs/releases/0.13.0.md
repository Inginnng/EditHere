0.13.0 新增项目组图评审和可选的 AI 解析，并修复截图选区、放大镜及 Windows 安装更新流程。

- **AI 维护项目组图**：桌面、Web、MCP Apps、连接器、Trae 与 DSH 的配套技能支持收集可访问页面、保留稳定页面标识、接收用户批注、修改源码并只替换需要更新的截图。用户可以继续在同一组图中评审下一轮结果。
- **只交付有关页面**：组图反馈只附有批注的页面；AI 解析只发送有修改的原图与结果图，大请求按页分批，整组文字意见不附截图。
- **AI 解析（预览功能）**：在编辑器底部或「查看 JSON」中，将截图、批注及几何调整转成另一位无图 Agent 可执行的文字需求。服务商可切换并记住，支持直接修改系统提示词；取消请求或往返设置保留已有草稿。结果仍需用户核对。
- **API 设置**：提供 OpenAI、Claude、DeepSeek、GLM、Kimi 及自定义兼容服务预设，API Key 存在系统凭据库中。请求使用用户自己的额度，图文只发往所选服务。
- **截图操作修复**：定格后连续拖动选区不再回弹，到屏幕边缘保留选区大小；放大镜显示没有遮罩、蓝框和角点覆盖的原始像素。支持不同显示缩放比例。
- **Windows IPC 加固**：统一校验进程令牌缓冲区、SID 范围与完整性级别，避免读取异常值；继续拒绝提权、跨用户和不同完整性级别连接。针对 #58 的报告已加入回归检查，报告者设备仍需复测。
- **剪贴板兼容**：独立「复制带批注图片」同时提供无损 PNG 与系统图像格式；「无法使用？」增加只粘贴到 JSON 时的分步投递方法。窗口较窄时可从「更多」菜单找到图片复制，第三方客户端的一次多文件粘贴行为仍取决于客户端。
- **macOS 外观**：使用系统红绿灯并修正标题栏同行布局；Dock/Finder 图标带圆角底板，菜单栏使用随明暗变化的矢量模板图标。启动缺录屏权限时静默驻留，手动截图时再提示。
- **安装和更新**：修复独立安装包空交接参数导致的安装失败。应用内更新遇到短暂断线或服务器错误时最多重试两次，仍执行原有签名、哈希和事务验证。发布时核对 GitHub 草稿实际收到的全部资产后才公开。
- **导出保真**：Web Agent 批注预览统一使用与内容一致的 PNG 文件名；原图、批注图和剪贴板图片保留无损像素。

录屏、马赛克/模糊遮挡以及 Linux ARM64 稳定分发尚未包含在本版。Windows 项目更新签名用于应用内验签，不是公开信任证书，首次下载运行的系统提示仍可能出现。
