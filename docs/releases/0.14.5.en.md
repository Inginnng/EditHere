# EditHere 0.14.5

[简体中文](0.14.5.md)

- In-app updates on Windows show an installation progress page that stays visible after the old app exits.
- When the update finishes, the new version opens an empty main window without taking a startup screenshot or asking an existing instance to capture one.
- Startup defers reading the installation receipt while an install transaction holds the lock, avoiding stale results from an earlier installation.
- Windows IPC is available to administrator and elevated processes without cross-privilege warning dialogs. Same-user SID checks, private directory ACLs, and random token validation remain in place.
