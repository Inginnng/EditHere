0.13.2 修复 Windows 开启 HDR 时截图可能全黑的问题。

- **空帧重试**：HDR 桌面采集的第一帧尚未绘制时，重新等待一帧；正常画面继续使用已有的 HDR 到 sRGB 颜色转换。
- **截图保底**：重试后仍为空帧时，普通截图和长截图改用 GDI 读取桌面并记录诊断。GDI 也失败时明确提示截图失败，避免把黑图作为成功结果保存。

感谢 foxfoc 提交 #71，并在 RTX 5080、HDR 开启的设备上复测普通截图恢复正常。维护者本机未开启 HDR，已分别验证颜色 / GPU 采集及回退失败路径；长截图在该 HDR 设备上的实际效果仍需继续确认。GDI 保底可能损失 HDR 颜色与高光，导出仍为标准 sRGB 图片。
