- **Fix a macOS long-capture crash**: on macOS, starting a scrolling capture and reading the first frame could close the app ([#39](https://github.com/Inginnng/EditHere/issues/39)). The frame is now read for the whole display and the selection is cropped locally, and an error from the system capture interface is reported instead of ending the process. Each stage of the capture is written to the diagnostics log, so a remaining failure shows exactly where it stopped.
- **Fix macOS save locations**: saving a project, an annotated image, a layout preview or the original image opened the dialog at the root of the file system, where the write always failed. Suggestions now start in Documents or Pictures.
