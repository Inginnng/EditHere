本次更新修复命令行工具无法连接桌面程序的问题，并修正随包交付的 AI 与命令行文档、配套 skill 和 JSON schema。

### 反馈格式说明

- **点批注为零面积区域**：指向某一点的修改意见在反馈 JSON 中表示为 `x1` 与 `x2` 相等、`y1` 与 `y2` 相等的零面积区域；AI 与命令行文档、配套 skill 写明按点处理，不当作没有位置的意见丢弃。
- **写明 schema 目录的对应关系**：当前精简反馈为 `feedback-minimal.schema.json`，`feedback-v1` / `v1.1` / `v2` 描述的是早期项目文档，`feedback-v0.7.schema.json` 是可继续导入的旧反馈格式。
- 连接器说明与安装配置文档指向当前反馈格式。

### 项目与反馈 schema

- **接受"手动切分"区域的原始范围**：这类区域在创建时记录成员的原始位置，之后移除成员也不会移动；schema 此前要求该字段为空，按它校验程序自己导出的项目会被判为非法。
- 完整项目与精简反馈的导出都纳入 schema 校验。

### 修复

- 修复命令行工具连不上正在运行的桌面程序的问题：命令行此前按自己的程序名推算通信端点，与桌面程序使用的名字不同，`status` 一直显示未运行，`open`、`capture`、`annotate` 报超时。附带效果是从 0.9.6、0.9.7 升级后，桌面程序不必重启，新命令行即可连上当前运行的实例。
- 修复公开 schema 比程序更严、拒绝程序自己导出的项目文件的问题。
