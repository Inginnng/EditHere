### 托盘单击与双击可配置

在 **设置 → 默认行为 → 托盘图标** 中，分别选择单击和双击动作：截图、新建批注（空窗口）、显示当前窗口、打开图片或项目、不执行操作。默认 **单击截图、双击打开空白窗口**。

单击会等待系统双击间隔，双击取消待执行的单击；右键菜单和快捷键立即响应。保存后即时生效，取消不应用，重启后保留。显示当前窗口保留当前文档，新建空白仍遵守未保存修改、AI 会话、截图与对话框保护。默认行为页面支持滚动，并提供简体中文、English 与繁体中文文案。

**平台范围：** Windows 支持单击和双击配置。Linux 的双击支持取决于桌面托盘是否发送相应事件。macOS 保留原生状态栏菜单，暂不支持自定义单击/双击；设置中禁用这两项并说明限制，请使用菜单动作或快捷键。
