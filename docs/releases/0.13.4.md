0.13.4 修复截图进入批注画布后，缩小或放大时文字不清晰、只有某个尺寸清楚的问题。

- **缩放显示**：缩小时从原图高质量重采样，保留细线和文字的整体信息；放大时平滑显示，避免最近邻采样造成的断笔和锯齿。
- **原始像素 1:1**：工具栏的 100% 现在表示一个原图像素对应一个屏幕像素。点击百分比，在“适应窗口”和“原始像素 1:1”之间切换；125%、150%、200% 系统显示缩放下也适用。
- **保留原图**：缩放只改变显示，不修改原图、批注坐标或导出数据。放大镜继续使用原始像素，保留像素网格和取色精度。

已验证四种显示缩放下的缩小、放大、1:1 还原、布局预览与放大镜。截图是位图，放大不会增加原图没有的细节。
