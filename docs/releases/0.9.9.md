本次更新新增 Linux x86_64 预览实现，统一批注图片的展示比例，并改进 Windows 更新流程与设置保留。

### Linux 预览（x86_64）

- 新增 Linux 实现：X11 / Wayland 截图与全局快捷键、XDG 开机启动、AT-SPI 元素识别、Tesseract 文字识别，以及命令行工具、AppImage 打包与 Linux 持续集成。
- 复用 Qt、桌面 Portal、AT-SPI、Tesseract 与 linuxdeploy，不额外引入运行时依赖。
- **本版 Linux 为预览**：目标环境为 Ubuntu 24.04 x86_64，其他发行版与 ARM64 尚未验证。
- Wayland 下截图先由系统完成授权与选区，再由应用审阅；系统不提供原始桌面坐标，因此不与桌面原生元素关联，交互与 Windows 不完全一致。
- 桌面不支持全局快捷键 Portal 时，可在系统快捷键中绑定 AppImage 完整路径与 `--capture`；无托盘宿主时保留编辑窗口入口，关闭窗口即退出。
- 文字识别使用本机已安装的 Tesseract，不联网、不上传，需自行安装引擎与语言包。
- 提供 AppImage、配套命令行脚本与 SHA-256 校验文件；更新通过发布页手动下载。

### 批注图片比例

- 复制与导出的批注图片采用统一图片展示宽度：相同宽高比、相同相对位置的批注，其编号、文字与侧栏比例保持一致，不再随原图分辨率变化；不同宽高比保留各自比例。
- 项目原图与批注坐标保持原有精度与位置。

### Windows 更新

- 安装版与免安装版共用 NSIS 更新流程。
- 更新前确认未保存的编辑；取消更新或安装器启动失败时保留当前程序。
- 下载使用独立临时目录与原子写入，强制校验 SHA-256，并补充超时、写入失败与启动失败处理。
- 安装先准备完整的新目录再切换，切换失败时恢复原有目录并保留备份。
- 检查更新时命令行工具无响应则改用公开接口；安装前的进程检查限定在目标目录内。
- macOS 与缺少兼容更新包的版本通过发布页手动下载。

### 设置

- 保存设置不再重置截图的圆角、阴影与边框。
- 升级保留开机启动设置与 PATH 选择。
