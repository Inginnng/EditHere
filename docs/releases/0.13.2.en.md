0.13.2 fixes screenshots that could turn entirely black with HDR enabled on Windows.

- **Retry blank frames**: wait for another frame when the first duplicated HDR desktop frame has not been painted. Valid frames retain the existing HDR-to-sRGB color conversion.
- **Capture fallback**: ordinary and scrolling captures read the desktop through GDI if the retry is still blank, with diagnostics recorded. If GDI also fails, report capture failure instead of accepting a black image as a successful screenshot.

Thanks to foxfoc for #71 and for confirming that ordinary screenshots work again on an RTX 5080 with HDR enabled. The maintainer's display has HDR disabled; color/GPU capture and fallback failure paths are checked separately. Scrolling capture on the reported HDR device still needs confirmation. GDI fallback can lose HDR color accuracy and highlights; output remains standard sRGB.
