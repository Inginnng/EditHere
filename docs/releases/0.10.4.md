# 0.10.4

- 安装、更新和卸载采用统一维护事务：目标目录互斥、持久日志与中断恢复、系统登记和快捷方式回滚、文件及运行版本验证。保留用户文件，移除新版不再使用的旧程序文件，卸载失败可以恢复后重试。
- 程序内更新等待安装器准备就绪后才退出；准备失败、取消和超时保留当前程序，下次启动读取安装结果。
- 修复 Windows 安装包放在目标目录或其子目录时安装失败的问题。按清单逐文件替换程序，安装包和用户文件保持原位，失败时恢复旧程序。
- 安装失败提示标明实际失败步骤，首次安装不再误称旧版本已保留。
- 已安装时显示「更新现有版本」，自动使用现有位置和选项，确认后直接进入更新进度；同版本重复安装采用相同流程。
- 修复原生 System.dll 被误当作 .NET 编译引用而导致安装及恢复失败的问题；系统通知失败会记录警告，不再中断已完成的登记。
- 默认在首次交互启动后检查更新，有新版时弹出「立即更新 / 跳过」。截图、AI 会话、使用引导和其他对话框期间延后提醒；无更新或检查失败时不弹窗，已关闭的检查设置保留。
- 更新复用 GitHub/Gitee 双源检查、SHA-256 下载校验及未保存修改确认。跳过不会退出程序，更新下载可取消。
- 增加安装包自占用目录及启动更新提醒的回归验证。
