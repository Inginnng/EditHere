0.13.1 为 Windows 截图增加 HDR / 高级颜色处理，并修正项目首页的说明。

- **截图颜色**：在启用高级颜色的显示器上，普通截图与长截图改用浮点采集，按系统当前 SDR 亮度转换为标准 sRGB，避免深色文字变浅、浅灰背景冲成白色。普通 SDR 显示器沿用已有采集方式。
- **采集稳定性**：按显示器处理竖屏、翻转、原生分辨率与纹理行步幅；长截图复用采集会话，结束后释放。浮点采集失败时明确报告失败并记录诊断，不使用已经丢失颜色的图像假装校正成功。
- **说明修正**：清除中英文 README 的残留合并标记，恢复桌面 / Web 对比表，保留三种界面语言、可选 API 请求与应用内更新签名的准确说明。

颜色转换、真实 GPU 像素、遮罩排除及重复采集已通过回归。本机未开启 HDR，#68 报告者设备仍需复测，因此该 issue 保留开放。导出结果为标准 sRGB 截图，超过 SDR 范围的 HDR 高光不作无损保留。
