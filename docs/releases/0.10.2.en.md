This update adds a global shortcut for “New annotation (empty window)”, so you can open the annotation window from another application, then drop, paste or import an image.

- The default shortcut is **Alt + Shift + 1**, or **Option + Shift + 1** on macOS.
- Change the combination or clear it to disable it in **Settings → Shortcuts**; saving applies the change immediately. The tray menu shows the current bindings for both “Capture” and “New annotation (empty window)”.
- Upgrading preserves existing settings and assigned shortcuts. If an older configuration already assigns `Alt + Shift + 1` to another action, the new shortcut starts disabled; choose another combination in Settings. A binding you explicitly clear stays disabled after a restart.
- Opening an empty annotation window follows the existing save-confirmation flow for unsaved changes. The new shortcut cannot replace or interrupt an active AI annotation session, capture or modal dialog.
