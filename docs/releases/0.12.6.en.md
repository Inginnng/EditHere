This patch addresses desktop window double-click and cross-monitor display behavior ([#51](https://github.com/Inginnng/EditHere/issues/51)).

- **Double-click the title bar to maximize or restore**: double-click the editor title bar or title text to maximize, then double-click again to restore. Full-screen windows and capture toolbars do not switch state.
- **Let the desktop move the window**: use the system window manager for monitor transitions, display scaling and snapping. Platforms without system moves retain the existing dragging behavior.
- **Paint a complete opaque Windows editor background**: avoid the translucent layered-window path that can leave large transparent areas when moving between monitors with different scaling. The window corners also have a painted background.

Physical dual-monitor setups with different scale factors still need verification on the affected machine. Automated checks cover double-clicks, maximize/restore, full-screen protection and complete Windows surface painting after moving and resizing.

Packages include the Windows installer and portable ZIP, universal macOS DMG, Linux AppImage, offline Web and Web Agent editions.
