This update improves Web and Agent annotation, feedback delivery, saving and setup.

- **Annotate comfortably in a small panel**: existing brand assets are retained, the toolbar adapts to available width, and annotation editing and component layout expand when needed. Square and portrait panels leave more room for the image.
- **Complete feedback inside an Agent**: hosts supporting MCP Apps can receive an image, show the annotation interface and retrieve structured feedback. The host controls whether it opens in the conversation or a side panel. Feedback is saved before delivery, failed delivery can be retried, and reopening restores saved drafts.
- **The save button follows your choice**: choose Save JSON file, Copy JSON content, Save project or View JSON file. The menu changes the selection; the main button performs it. Files and copied content match, with an option to include the source image and counts and size information.
- **Easier setup**: added the Web installation guide (`web/AI-SETUP.md`) and a local preview script (`web/preview.cjs`); for first-time setup, hand the guide and the package to your Agent.
- Removed the standalone HTML download and 1:1 buttons; offline editing uses the standalone HTML from the distribution. Added visual tutorials and recovery guidance for feedback, clipboard and image issues.
- Image feedback retains the desktop-compatible JSON structure, annotation order and coordinate precision. Web and Web Agent are packaged separately; entry points and platform limits remain documented in each package.
