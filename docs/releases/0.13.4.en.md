0.13.4 fixes broken text strokes, missing fine lines and jagged edges when screenshots are resized in the annotation canvas.

- **Scaled views**: reductions use high-quality resampling from the original image; enlargements use smooth interpolation instead of nearest-neighbor sampling.
- **Native pixels**: 100% now means one image pixel per display pixel. Click the percentage to switch between fitting the window and native 1:1 pixels, including at 125%, 150% and 200% system scaling.
- **Originals preserved**: zoom affects only the view. Original images, annotation coordinates and exported data remain unchanged. The magnifier continues to display original pixels with its pixel grid and accurate color sampling.

Checks cover reduction, enlargement, native-pixel restoration, layout previews and the magnifier at four display scale factors. Enlarging a bitmap cannot add detail absent from the original screenshot.
