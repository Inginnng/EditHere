# EditHere 0.14.8

[简体中文](0.14.8.md)

- Add Simplified Chinese, Traditional Chinese, and English to the workspace UI, with automatic matching when the language follows the system; window copy, toasts, and export file names are localized too.
- Append new screenshots, scroll captures, and clipboard images as pages of the current workspace, with automatic page-name deduplication.
- Unify shortcut recording and matching on one portable key description that supports multi-step chords and no longer fires while typing in an input field.
