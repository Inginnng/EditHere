# EditHere 0.14.0

- **品牌与图标重塑**：产品名称统一为 `EditHere`，全新设计的精密取景器 + 钴蓝锚点应用图标与单色几何字标（移除早期偏玩具感的蓝色方框铅笔图标与橙帽铅笔字标）。
- **批注工作台升级**：优化短屏/窄屏自适应布局与悬浮标注卡片交互，工具栏按原图编辑/批注操作分层归组，统一框选边框、控制点尺寸与语义描边刻度。
- **截图与长截图一致性**：统一自由选区与滚动长截图的工具条外观、圆角透明渲染、状态胶囊及 UIA+像素边界联合识别逻辑。
- **MCP 连接与自动化测试**：新增统一 CLI & MCP 网关（`cli/unified-mcp.mjs`），修复桌面端诊断页 `unified-mcp.mjs` 路径解析，补全覆盖统一 MCP、连接器 MCP 与 Web MCP 端到端链路测试。
