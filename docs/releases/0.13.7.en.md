0.13.7 improves image pasting and desktop window controls.

- Paste image files copied from your file browser directly into EditHere. Pasting multiple images opens them as an image set.
- On macOS, the editor toolbar sits below the system title bar so the top-right buttons remain visible and clickable. Wheel and trackpad zoom use finer steps.
- On Windows, a maximized editor can return to its original size after being hidden, minimized, or switched to full screen.
