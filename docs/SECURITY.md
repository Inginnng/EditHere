# 本地通信与更新验证

## 本地通信

桌面转发和 Agent IPC 在执行命令前校验本轮 GUI 生成的 256-bit 随机凭据。凭据位于仅当前用户可访问的私有目录，每次 GUI 启动轮换；CLI 和第二个 GUI 自动读取，无须把 token 放入 MCP 配置、命令行或日志。

通信双方同时校验操作系统身份：Unix 校验 UID，Windows 校验 SID 与完整性级别。Windows 提权运行的 GUI 停用 IPC，仍可手动使用。升级后先保存工作，再重启 GUI，并使用配套 CLI；旧的无认证命令不会降级执行。

信任边界是当前操作系统账号及其完整性级别。能够读取当前账号凭据、调用合法 CLI 或注入当前账号进程的恶意程序仍在这个边界内；token 不能隔离同账号的任意恶意程序。不要向其他账号或不可信执行环境共享凭据目录。

## Windows 更新

程序内安装先校验同名 SHA-256，再按编译时选定的信任模式验证安装包。下载服务器、发行元数据、运行时环境或设置均不能提供或替换信任根。验证至启动期间持有不允许写入或替换的文件句柄；身份验证失败时，不显示安装确认，也不启动安装器。

- **证书模式**：构建参数 `EDITHERE_UPDATE_PUBLISHER_CERT_SHA256` 非空时，必须通过 Windows Authenticode 及内置发布者证书 DER 的 SHA-256 指纹验证。无效配置在构建时失败；签名失败绝不回退到项目签名。
- **项目签名模式**：未配置证书指纹时，使用 `app/updatekey.h` 中编译的 P-256 公钥。Windows 原生 CNG（bcrypt）以 ECDSA P-256/SHA-256 验证，不新增加密运行库。公钥为空时仍停用程序内安装，只提供发布页。
- **首次迁移**：0.12.7 及更早版本需要手动安装一次含正式公钥的版本，此后可验证后续签名更新。项目签名不等于公开信任的 Windows 代码签名证书；“未知发布者”和 SmartScreen 提示仍可能出现，不修改系统信任存储、不关闭安全检查。

签名文件为精确安装器名加 `.sig`，上限 1024 字节；校验文件上限 4096 字节。签名载荷按 ASCII/LF 严格拼接（最后一行也有 LF）：

```text
EditHere Windows Update Signature v1
<无 v 前缀的 X.Y.Z>
<精确安装器文件名>
<64 位小写十六进制 SHA-256>
```

其后追加一行 64 字节 IEEE P1363 `r||s` 签名的规范 Base64（88 字符）及 LF。CNG 验证的是上述载荷的 SHA-256 预哈希。版本分量是无前导零的非负 32 位有符号整数；签名安装器仅接受稳定名称 `EditHere-win-x64-setup.exe` 或与版本精确对应的历史名称。新发布只签最终稳定名称。版本必须高于运行客户端，阻止把旧签名重放为新版；不接受跨版本、跨文件名、不同哈希、改动/缺失/超限或非规范签名。

包、同名校验和及同名签名必须来自同一仓库、来源、版本标签；同版本优先完整签名集合，不能拼接镜像资产。新版缺少签名时仍展示新版并提供手动下载，不用较旧的签名包冒充新版。下载取消、失败、重试和对象销毁都终止并回收元数据请求。

发行私钥仅用于标签发布的签名步骤；环境变量/仓库 Actions Secret 名为 `EDITHERE_UPDATE_SIGNING_KEY`，值为 P-256 未加密 PKCS#8 PEM（LF），不得放入命令行、源码、产物或日志。PR 和平台构建不接收私钥。发布步骤在所有字节变更、稳定命名和 SHA-256 生成后签名，核实标签/源码版本及公私钥匹配，再以仅公钥的独立步骤复验；缺失或不匹配立即终止发布。公钥/证书轮换要经现有信任链或明确的手动升级交付，不能从同一发行动态接受。私钥配置及备份须有单独授权，测试私钥不得充当生产信任根。

GitHub 发行版先保留为草稿，上传后通过 GitHub API 逐个核对资产的状态、字节数和 SHA-256，全部一致才公开。重跑可以补传未公开的草稿，但不会覆盖已公开的同标签发行版。该检查覆盖发布链路；客户端仍按内置公钥或证书验证实际下载的安装包。

## 反馈文件发布

反馈以临时文件写入，再通过原子且禁止替换的操作发布：Unix 使用 `link()`，Windows 使用不带替换标志的 `MoveFileExW()`。若另一个进程先占用目标路径，发布失败并保留已有目标，不跟随目标符号链接、不覆盖文件。路径预检查只负责友好的错误提示，最终发布操作负责避免覆盖。`linkat(..., AT_SYMLINK_FOLLOW)` 的标志针对源路径，不能消除目标被提前占用的情况，因此不作为该问题的修复。
