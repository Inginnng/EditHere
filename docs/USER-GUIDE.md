## 运行与更新

### 安装

首次更名升级请从[最新发布页](https://github.com/Inginnng/EditHere/releases/latest)直接下载新包，先从托盘退出旧版。不再兼容旧版项目格式，请使用 `.edithere` 项目。如果开机启动提示旧路径，保持自启勾选并保存即可刷新，无需先关再开。在新程序中保存一次项目会登记 `.edithere` 文件关联。旧版的自动更新检查可能不识别改名后的地址。

Windows 推荐使用[安装器](https://github.com/Inginnng/EditHere/releases/latest/download/EditHere-win-x64-setup.exe)（本地构建产物形如 `dist/EditHere-<版本>-win-x64-setup.exe`，发布时统一为不带版本号的文件名）。发布资产名不含版本号，链接始终指向最新版本。默认安装到 `%LOCALAPPDATA%\Programs\EditHere`，仅安装给当前用户，无需管理员权限。安装器创建开始菜单和卸载入口，登记 `.edithere` 项目关联；组件页可选择登录启动、加入 PATH 与桌面快捷方式。新安装默认勾选登录启动和 PATH；升级时根据已有当前用户启动登记保留启动选项。安装完成后重新打开终端与 AI 工具，才能读取新 PATH。

Windows [免安装版压缩包](https://github.com/Inginnng/EditHere/releases/latest/download/EditHere-win-x64.zip)：本地构建产物形如 `dist/EditHere-<版本>-win-x64.zip`。完整解压并运行 `EditHere.exe`，保留同目录 DLL 和插件文件夹；无需安装 Qt、Python、Node 或 .NET。免安装版不自动添加 PATH，可用完整路径运行 CLI。

Windows 安装包尚未进行代码签名。请从本仓库 Releases 下载，并核对[程序包 SHA-256 校验和](https://github.com/Inginnng/EditHere/releases/latest/download/SHA256SUMS.txt)。在下载目录打开 PowerShell，可用 `Get-FileHash .\EditHere-win-x64-setup.exe -Algorithm SHA256` 计算安装包的哈希，与文件内同名条目比较。

macOS 下载[通用版 DMG](https://github.com/Inginnng/EditHere/releases/latest/download/EditHere-macos-universal.dmg)，打开后将 `EditHere.app` 拖到其中的 **Applications** 入口。CLI 位于 `EditHere.app/Contents/MacOS/edithere-cli`。首次截图需屏幕录制权限，系统元素识别需辅助功能权限；尚未实机验收和 Apple 公证。

Windows 可通过系统"已安装的应用"或开始菜单中的卸载入口移除安装版。卸载仅移除随包安装的文件及其登记，保留用户设置与项目；无需为更新版本删除这些数据。

安装或升级时若 EditHere 正在运行，安装器会先请运行中的实例自行退出（未保存的批注仍走应用自身的保存提示，窗口会自动浮到前台），等待进程结束再继续写入文件；静默安装不弹窗。也可用 `EditHere.exe --quit` 请求运行中的实例按正常流程退出。

### 应用内更新

在 **设置 → 关于与更新** 中点击**「检查更新」**，或右键托盘选择**「检查更新…」**。Windows 发现兼容的新版本时显示**「立即更新」**，下载并校验 SHA-256 后，先确认未保存的编辑，再启动安装器并退出；取消确认或启动失败时不退出。安装版和免安装版共用 NSIS，便携更新不会登记安装、修改 PATH 或创建快捷方式。便携更新要求目标发行版至少为 0.9.9；没有兼容包时以及 macOS 上，按钮打开发布页供手动下载。

更新会在原目录旁准备新目录，再切换目录；需要父目录写入权限及额外磁盘空间。失败时尝试恢复旧目录，成功后也保留旧目录备份，其路径记录在程序目录的 `update-backup.txt`（UTF-16LE 文本）中；确认新版本正常且备份没有需要保留的独有文件后，可自行删除备份。勾选**「启动时检查更新」**后，每次启动自动检查一次。检查与更新访问 GitHub，截图与批注数据不随更新上传。

旧版客户端在更名升级后可能不识别新的下载地址，首次更名升级请使用上面的下载入口手动下载一次。

### 启动与托盘

首次手动启动先显示使用引导；完成或跳过后不再自动显示。之后按 **Alt + Shift + 2** 或点击托盘图标截图。快捷键截图不模拟按键或激活临时窗口；托盘入口会先关闭菜单和弹层，再采集画面。取消、复制或保存截图后恢复原窗口。已有快捷键设置保持不变，可在设置中恢复默认。只有截图遮罩置顶，编辑窗口是普通应用窗口。

托盘菜单依次为：**截图**（右侧显示当前全局快捷键）、**新建批注（空窗口）**、**打开图片或项目**、分隔线、**设置…**、**检查更新…**、分隔线、**退出**。macOS 上还会多出一项**授予辅助功能权限**的入口，用于读取系统元素边界；未授权时图片识别仍可直接使用。

下文列出默认快捷键，可在[设置](#设置)中修改对应键盘操作。

## 截图

- 悬停智能选块；滚轮向上选择更大区域，向下选择更小区域。所有已识别、包含鼠标位置的框都可切换，无须互为父子。**滚轮选过的那一级会记住**：切到「整行 / 整张表」之后，再怎么移动鼠标、按方向键，选中的都还是那一级；想回到最小的一块就把滚轮往回滚，开始新一次截图时也会重新从最小的一块开始。**用方向键微调时，选中的框不会变**：一格一格挪指针做微调时，选中的块保持不动，不会挪进里面的按钮或单元格就缩成那个小元素。用鼠标大范围移动仍然是智能选块，指到哪儿就选哪儿。**方向键一格一格移动鼠标指针**（一次一格，只动被按的那个方向，在缩放屏上也是准确的一格），识别框高亮与放大镜跟着走，用来对准某一个像素；从进入截图到选区定下来，一直都能用。
- 单击选块或拖动画框，**松开鼠标后选区就定下来**，并在它**上方**出现截图工具条，在它**右侧**出现一列样式工具；上方空间不足时工具条自动移到下方。进入批注是工具条上的一个动作（点「批注」或按回车），不再是松手的默认结果。
- 选区定下来之后仍可调整：在区域内拖动是移动，拖四角是缩放，在区域外重新拖动是重新框选；**方向键移动的是鼠标指针**（一次 1 像素，放大镜跟着走，用来对准某一个像素），`Shift` + 方向键从那一侧收缩 1 像素，`Ctrl` + 方向键向外扩展 1 像素。Esc 取消截图。

### 截图工具条

| 动作 | 默认快捷键 | 说明 |
| --- | --- | --- |
| 批注 | Enter | 进入批注编辑器 |
| 复制图像 | Ctrl + C | 把选区（含已选的圆角、边框、阴影）放进剪贴板 |
| 贴图（置顶） | Ctrl + T、Ctrl + 2、P | 把这一块钉在屏幕上，**贴回它原来所在的位置**，见下方说明 |
| 保存图片 | Ctrl + S | 另存为 PNG 或 JPEG |
| 文字识别 | Shift + C、T | 打开识别结果窗口，见下节 |
| 长截图（开发版，Windows） | L | 手动向下滚动页面，自动拼接并显示预览 |
| 取色 | C | 只在快捷键里，工具条上没有按钮：进入取色后放大镜跟着鼠标走，再按 C 或 Ctrl + C 复制颜色值（不按 C 时读数也一直显示在放大镜旁） |
| 历史截图上一张 / 下一张 | < / > | 不离开截图窗口就把更早的截图翻出来 |
| 恢复上次选区 | R | 直接采用最近用过的选区尺寸 |
| 更多选项 | H | 打开工具条菜单 |
| 取消 | Esc | 放弃本次截图 |

- 工具条左边显示选区的左上角坐标与「宽 × 高 px」，点它可以键入精确尺寸；锁定了比例时，高度由比例推出。
- 选区右侧的样式列是：**圆角**、**阴影 / 边框**、**重置**。圆角与阴影各打开一个小面板，用滑块调；阴影面板有「阴影 | 边框」两个页签和一个强度滑块（0–100），勾上「每次截图都设置」之后，这个样式会写进设置，以后每次截图都从它开始。**贴图只在工具条上出现一次**，不再在样式列里重复一个。
- 拖动选区时，指针旁会有一个**放大镜**，把指针附近放大十几倍。它放大的是**屏幕上看到的那一层**：蓝框、变暗的周围都跟着一起放大，框有多粗放大后就有多粗。面板里还给出像素坐标与 `RGB` / `HEX` / `HSV` / `HSL` 读数。选区定下来之后，只要鼠标还在选区内，放大镜与读数就一直都在，不必先进取色。放大镜自动避让工具条与样式列。
- 「更多」菜单里还有：固定比例（1:1、4:3、3:2、16:9、9:16、自定义如 `21:9`）、文字识别语言、截图历史（含上一张 / 下一张）、最近的选区，以及当前快捷键一览。
- 圆角与边框在选区上**所见即所得**地预览；复制、保存、置顶、识别拿到的都是带上这些效果的成品图。阴影**默认开着**（中等强度），把强度滑块拖到 0 即关闭；它会把图片四周各扩出对应像素，且是平滑衰减的，越往外越淡，颜色用的是界面的强调色——就是选区那一圈蓝——不是黑色。阴影**只画在置顶的图片上**，截图窗口里不铺：调好强度后贴一次图就能看到效果。文字识别读取截图本体，不含阴影外扩的部分。
- 最近 **20 张截图**与最近 **10 个选区**跨会话保留。截图时按 `H` 从最近 5 张里挑一张直接打开，按 `R` 恢复最近用过的选区尺寸。

**取色**：进入取色后放大镜跟着鼠标走，指到哪儿就读哪儿的颜色。面板里给出像素坐标、一个色块，以及 `RGB`、`HEX`、`HSV`、`HSL` 四种写法；`Shift` 在这四种之间循环，颜色最深的那一种就是会被复制的那一种。按 `C` 或 `Ctrl + C` 复制颜色值，点一下鼠标也复制并结束取色，`Esc` 或右键结束取色。

**置顶窗口**可以同时钉多张，默认就落在刚才截图的那个位置。

- **移动**：在图片中间按住拖动。
- **缩放**：鼠标移到图片**边缘或四角**，光标会变成对应的缩放光标，按住拖动即可放大缩小；滚轮也可缩放（10%–400%），按 `0` 适应屏幕。两种方式共用同一个缩放比例，拖完之后接着滚轮不会跳回去。
- 图片的边缘由**阴影**交代，不额外描线。在右键菜单里把阴影关掉后，图片上**什么线都没有**：它只是一张摆在桌面上的图，桌面颜色相近时看不出边界。可以拖动的边缘仍然存在，只是不再画出来。
- **阴影还说明正在用哪一张**：点中的那张阴影是**蓝色**的；鼠标点到别的窗口之后，它的阴影变**灰色**。同时钉了好几张时一眼就分得清。把阴影关掉的图两种颜色都不出现。
- `Ctrl + C` 复制；**双击或 `Esc` 关闭**。
- **右键菜单**：第一项是**批注**（把这张图交给编辑器，阴影不计入画布），其后是复制图像、保存图片、文字识别、**旋转**（向左/向右 90°、水平翻转、垂直翻转）、**透明度**（100% / 75% / 50% / 25% / 10%）、**阴影**（可随时开关）、缩放（适应屏幕 / 原始大小 / 回到截图位置）与关闭。从别处直接贴进来的图没有可开关的阴影，该项会置灰。
- 带阴影的图会把阴影一起带过去，四周透明的那一圈透出桌面。

### 直接打开一个空批注窗口

已经躺在磁盘上的图片不必再截一次：托盘菜单里的**「新建批注（空窗口）」**会直接打开批注窗口，中间写着「可直接拖入或粘贴图片」，下方是**「导入图片或项目」**按钮。图片**拖进窗口**即可开始批注，按 `Ctrl + V` 粘贴同样可以，点按钮则从文件里选一张图或一个项目。

关闭批注窗口时如果还有未保存的修改，会问「是否先保存项目」。这个弹窗上有**「不再提醒，可在设置中修改」**：勾上之后，以后关闭窗口直接放弃未保存的修改，不再弹窗。想改回来，去**设置 → 默认行为**里把「关闭批注窗口时询问是否保存」勾上即可。

### 长截图（开发版，Windows）

先把页面滚到需要的起点，框选滚动内容，再点击工具条的「长截图」或按 `L`。默认由你在选区内慢慢向下滚动，程序等待画面停稳后自动拼接，并显示实时缩略预览；固定顶栏和底栏只保留一次。停下滚动会继续等待，想截到哪里就点击「完成长截图」。选区应位于同一个滚动区域内，尽量避开浏览器工具栏和独立侧栏，避免一次滚过整屏而没有重叠内容。

需要程序代为滚动时，勾选预览窗口中的「自动滚动」，也可以随时取消勾选回到手动；每次开始长截图时该开关都关闭。自动模式确认到达末尾后会完成，手动模式由你点击「完成长截图」。点击「停止」会停止采集，已经拼好的部分仍可完成并进入批注编辑；`Esc`（预览窗口有焦点时）或「返回选区」放弃本轮长截图并回到原选区。画面持续变化或重叠无法可靠匹配时会暂停；没有新增内容时不能完成，不会把第一帧当成长截图。

当前实现为 Windows 纵向长截图。Mac、Linux 和横向长截图暂不支持；结果遵循编辑器的 3200 万像素及 32767 像素边长限制。设计参考和验证入口见 [长截图实现参考](LONG-CAPTURE.md)。

### 文字识别

- 识别结果在独立窗口里**逐行**列出，点某一行会高亮它在原图上对应的位置，便于发现读错的地方；可以复制全部、只复制选中行、或换个语言重新识别。
- 识别语言在 **设置 → 外观 → 文字识别语言** 里选（跟随系统 / 简体中文 / English），也可以在截图工具条的菜单里就地切换，选择会被记住。
- 识别用的是**系统自带能力，不联网、不上传、不新增依赖**：Windows 用系统自带的 OCR 引擎，macOS 用 Vision。系统没装对应语言的识别包时，窗口里会给出该到哪里添加的提示。
- 图片比识别引擎的上限更大时，会按条带切分后逐段识别，再把行框还原到整张图的坐标，所以大图不会丢行也不会错位。

## 批注编辑

- 顶部工具依次为**智能选块**、**点标注**、**框选**、**调整批注**；其后是**大爆炸**、撤销、重做、**适应图片**、**隐藏 / 显示画面批注**、**全屏**，以及收起批注栏的按钮。默认工具在**设置 → 工具栏 → 默认标注工具**里选。
- 批注栏从一开始就固定预留。点编号或移动箭头，在右侧直接编辑，离开输入框自动保存；右上角加号可添加全局意见。框选松开立即在侧栏输入批注，并保留手动区域供组件调整。窗口变窄时可用批注栏上的按钮收起侧栏。
- 空白处滚轮或 `Ctrl` + 滚轮以鼠标指向的位置缩放整张图片；按住鼠标中键可自由平移，图片比窗口小时也能拖动，并可越过图片四边，普通批注与大爆炸模式一致。`Ctrl + 0` 适应窗口。普通窗口下拖动顶栏，或按住空格 / `Alt` 拖动画面，可移动窗口。
- 调整工具可移动或缩放批注框；单击编号编辑文字。`Ctrl + Z` 撤销，`Ctrl + Y` 重做，`Delete` 删除所选批注。
- 支持打开、拖入或粘贴 PNG / JPEG / WebP / BMP，以及重新打开 `.edithere` 项目或反馈 JSON。
- 关闭当前截图会提示保存未存修改，随后释放截图和切块缓存；程序仍驻留托盘。
- 顶部**眼睛**按钮隐藏画面上的标记，保留右侧批注文字，便于查看原图或导出干净的对比图。

Mac 编辑快捷键使用 Command，重做为 Command + Shift + Z，截图为 Command + Shift + 2。Mac 尚未实机验证。

## 视频标注

通过打开文件或拖入视频开始播放。拖动时间轴或使用 `−1s` / `+1s` 定位后，停在目标画面供批注：暂停中定位保持暂停，播放中定位后也暂停。再次点击“播放”或按空格继续播放，找到其他时间点后再添加下一组批注。时间轴上的橙色标记与“已标注画面”列表可回到已有批注的位置，空格可控制播放与暂停（在文字输入框中仍输入空格）。

保存 `.edithere` 视频项目会引用源视频地址，内嵌已标注帧的原图和编辑状态。源视频移位或丢失后仍可查看保存的截图，点击“重新指定视频”恢复播放。导出 JSON 使用 `video-feedback-1`：每帧包含实际截图时间戳、图片反馈和可选内嵌截图，根对象索引给每个图形标注附 `timestampMs` 与 `frameId`。

时间戳相对源视频起点，坐标为对应帧截图的像素。不同时间点的相同坐标是独立反馈；AI 需要同时读取时间、截图和意见。完整结构、截图文件的分享方式与实际验证记录见 [视频标注说明](VIDEO-ANNOTATION.md)。本轮视频功能实机验收为 Windows，其他平台以各自构建和验收结果为准。

## 大爆炸

点击顶部"大爆炸"按钮，按钮变色，并播放从右上向左下扫过的虹彩波浪。组件直接在**当前窗口**内调整。

首次进入会按识别框切块；再次点击按钮关闭模式时，画面保留调整结果，切块缓存继续保留。重新开启会使用同一套切块及调整数据，不会重新切分；关闭当前截图后才清除缓存。

大爆炸开启时，右侧始终保留批注；点标注工具可在结果上添加意见，编号和移动箭头可直接点击编辑。智能工具用于选块和调整，框选用于补充手动区域；选中组件后可从右侧添加批注。组件调整区固定在侧栏底部，批注列表独立滚动。附着在组件上的批注随组件移动、缩放，编辑结果和批注使用同一套画布坐标。

| 操作 | 行为 |
| --- | --- |
| 未选中时悬停并滚轮 | 遍历包含鼠标的全部候选范围 |
| 单击候选范围 | 选中组件或组件组 |
| 拖动已选区域内部 | 移动组件 |
| 拖动边缘中点 | 改变宽度或高度 |
| 拖动角点 | 等比例缩放，无需 Shift |
| 指向已选组件时滚轮 | 等比例放大或缩小组件；指向空白处缩放整图 |
| 右侧 X、Y、宽度、高度、缩放 | 精确设置像素位置、尺寸和比例 |
| 方向键 | 移动 1 px |
| `Ctrl` + 点击 | 多选，选中的块一起拖动或变换 |
| 右键、Esc 或"取消选择" | 返回悬停选块 |
| 底部"框选"后画框 | 添加可操作区域，爆炸前后均可使用 |
| `Ctrl` + 滚轮 | 缩放视图 |

选择大框时，内部组件一起移动、缩放，并保留相对布局；块被移出父组后即脱离父组，父组移动不再带动它。支持撤销和重做。移动后原位置留空，以透明棋盘格显示；不补背景、不恢复被遮挡的内容。调整限制在原图大小的画布内。

移动在发生时即成为一条批注，与文字批注同列并按发生顺序排列，位置不受之后补写文字的影响；它可以没有文字，点开即可补写，编号与画面上的箭头一致。把块移回原位后，没有文字的移动批注一并移除，已写过文字的批注保留。

- **复制 JSON 内容**：复制 JSON 文本，适用于只能粘贴文字的 Agent。
- **保存 JSON 与图片**：把 JSON 与配套图片保存到指定目录。

复制 JSON 与导出 JSON 采用同一种精简结构，字段见[反馈 JSON](#反馈-json)。

## 反馈 JSON

图片反馈采用**面向对象**结构：每个对象记录一块来源区域 `source`、它发生的位置变化 `movements`，以及挂在这块区域上的意见 `annotations`，AI 可直接把同一对象的意见与移动对应起来。视频反馈在 `frames[].feedback` 内复用这份结构，并补充帧时间戳、源视频信息和带时间戳的对象索引，详见 [视频标注](#视频标注)。

| 字段 | 含义 |
| --- | --- |
| `image` | 可选的调整前图片 data URL（PNG，或勾选压缩后的 JPEG）；尺寸保持不变，压缩会损失少量细节 |
| `annotationSpace` | 固定为 `"result"`，表示批注坐标对应当前调整后的画面 |
| `objects[].source` | 该对象在原图中的区域；全局意见为 `null` |
| `objects[].movements` | 按顺序记录这块区域的移动或缩放结果，`to` 为最终坐标 |
| `objects[].annotations` | 挂在该对象上的文字意见 |

图片反馈中没有发生变化的组件不导出；不输出完整切片清单、组件组引用、哈希或时间戳。原图 Base64 会增加文件体积，这是把图片放进单个 JSON 的数据开销，与组件数量无关。图片格式由 `schema/feedback-minimal.schema.json` 定义；视频反馈和项目分别由 `schema/video-feedback-v1.schema.json`、`schema/video-project-v1.schema.json` 定义。

坐标以画布左上角为原点，单位为图像像素，与窗口位置和视图缩放无关。框使用 `x1/y1/x2/y2` 两个端点；右下边界不包含自身，宽高为 `x2-x1`、`y2-y1`。批注坐标为整数，布局变化坐标可含小数。

以下示例省略可选的 `image` 字段，展示一条点意见、一条区域意见、一个移动后的对象，以及一条全局意见：

```json
{
  "annotationSpace": "result",
  "objects": [
    {"source": {"x1": 240, "y1": 180, "x2": 240, "y2": 180},
     "movements": [], "annotations": ["这里改为蓝色"]},
    {"source": {"x1": 200, "y1": 140, "x2": 400, "y2": 240},
     "movements": [], "annotations": ["增加圆角"]},
    {"source": {"x1": 100, "y1": 100, "x2": 300, "y2": 200},
     "movements": [{"to": {"x1": 200, "y1": 140, "x2": 400, "y2": 240}}],
     "annotations": ["整块往右下挪一点"]},
    {"source": null, "movements": [], "annotations": ["整体更轻盈、安静，减少装饰"]}
  ]
}
```

还原结果时，先从原图提取每个对象的 `source` 区域并将原位置留空，再按 `movements` 顺序绘制到 `to`；最后在结果上解释或绘制批注。未移动的区域保持原样。

早期版本使用的 `annotations` 与 `changes` 并行数组（旧格式）仍可导入，导入后按来源区域合并为对象结构：

| 格式 | 原图 | 批注坐标 | 布局信息 |
| --- | --- | --- | --- |
| 0.5 及以前的 v1/v1.1/v2 项目 | `capture.pngBase64` 可内嵌，或引用外部 PNG | 原图 | v2 保存全部切片、分组及原始/目标坐标 |
| 0.6 精简反馈 | 外部同名 PNG | 原图 | 仅变化的 `from/to` |
| 0.7 / 0.8 反馈 | `image` 可内嵌 | 调整后的画面 | `changes` 中仅变化的 `from/to` |
| 0.9 起（当前） | `image` 可内嵌，界面默认包含 | 调整后的画面 | `objects` 中按对象记录 `source` 与 `movements` |
| 3.0.0 `.edithere` 项目 | 始终内嵌原图 | 调整后的画面 | 完整切块缓存和当前编辑状态 |

应用不再打开旧版项目及 0.6 精简反馈，旧批注不再转换到调整结果的位置。取消包含原图时，重新打开需要配套的同名原图 PNG。`.edithere` 项目保存完整切块及编辑状态（`schemaVersion: "3.0.0"`），重新打开直接恢复。关闭截图会释放内存缓存。重新打开反馈 JSON 时，从原图和其中的变化重建布局。

### 外观

- **外观模式**：跟随系统、亮色、暗色，默认为跟随系统。切换后，编辑器、批注栏、组件侧栏、菜单和设置窗口统一更新；原图与导出图片的原始像素不受主题影响。
- **界面语言**：跟随系统、简体中文、English。切换后立即预览，保存后生效，取消则回到原来的语言。系统的文件对话框、消息框与颜色选择器一并跟随。导出给 AI 的 JSON 字段值不随界面语言变化。
- **文字识别语言**：跟随系统、简体中文、English，用于截图工具条的文字识别，也可在工具条菜单里就地切换。

## 使用引导与开机自启

- 首次手动启动在真实编辑窗口展示六步引导，可随时跳过；没有截图时使用示例，有截图时保留原内容。右上角 **?** 和设置底部的 **使用引导** 均可从头开始。引导可前后翻页，Esc 只退出引导。
- 引导状态与设置偏好分开保存，恢复默认设置不会让引导反复出现。从设置重看引导会关闭设置窗口，不保存尚未应用的修改。
- 登录系统后仅驻留托盘，不自动截图；"启动后立即截图"只用于普通手动启动。

## 与 AI 配合使用

你可以手动复制 JSON，也可以让接入 CLI 的 AI 发起标注会话。后一种方式中，AI 打开图片，你添加批注或调整组件，最后点击顶部 **"完成并返回 AI"**；CLI 此时才导出本轮反馈并返回成功。点击"取消"或等待超时不提交反馈，编辑器保留当前文档。连接中断时结果可能不明，需核查本轮是否已经完成，不能直接重复发起会话。

每轮反馈使用新的输出文件，AI 只读取本轮明确提交的结果，不能将之前的文件当作新意见。配套 skill 的安装、命令和示例见 [AI 与命令行](AGENT-CLI.md)。

## 识别与平台边界

图片识别完全在本机运行，采用颜色连通区域、边缘聚合及横竖线网格分析，不需要网络、账号或模型下载。它能识别卡片、图片和较清晰的轮廓，但不是 OCR 或语义物体识别，不能保证每个候选都是用户理解的组件；可手动画框补充。

Windows 使用 UI Automation、Mac 使用 Accessibility 读取目标应用公开的元素边界。探测在独立短进程中运行，超时会停止。识别信息不包含代码仓库里的 DOM、组件名或源码位置；网页 DOM 标注仍是独立方向。

当前每次截取一块显示器内的区域，不跨屏拼接。混合缩放、多屏布局、托盘展开面板、受保护画面及不同浏览器仍需要更多设备验证。

| 平台 | 状态 |
| --- | --- |
| Windows x64 | 在 Windows 11 开发与测试；最低构建目标为 Windows 10 1809+，未逐一测试旧系统 |
| Windows 截图与 UI Automation | 已用本程序真实测试窗口校验像素、物理尺寸和按钮边界 |
| Windows 托盘面板与多屏 | 仍需更多真实环境验收 |
| Mac | GitHub macOS 构建与自动测试已通过，生成临时签名 DMG；**尚未实机验收** |
| Mac ARM / Intel | 已编译 arm64 + x86_64 通用程序，CI 在 Apple 芯片环境运行测试；Intel 尚未运行验收 |

Mac 目标为 macOS 14+，使用 ScreenCaptureKit。首次截图需屏幕录制授权；系统元素识别需辅助功能授权，托盘菜单提供入口。普通图片导入无需这些权限。目前没有可用的 Mac 测试设备。公开 Mac 发行还需产品所有者的 Apple 签名和公证。
