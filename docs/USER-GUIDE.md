## 运行

首次更名升级请从[最新发布页](https://github.com/Inginnng/EditHere/releases/latest)直接下载新包，先从托盘退出旧版。不再兼容旧版项目格式，请使用 `.edithere` 项目。如果开机启动提示旧路径，保持自启勾选并保存即可刷新，无需先关再开。在新程序中保存一次项目会登记 `.edithere` 文件关联。旧版的自动更新检查可能不识别改名后的地址。

Windows 推荐使用[安装器](https://github.com/Inginnng/EditHere/releases/latest/download/EditHere-win-x64-setup.exe)（本地构建产物形如 `dist/EditHere-<版本>-win-x64-setup.exe`，发布时统一为不带版本号的文件名）。发布资产名不含版本号，链接始终指向最新版本。默认安装到 `%LOCALAPPDATA%\Programs\EditHere`，仅安装给当前用户，无需管理员权限。安装器创建开始菜单和卸载入口，登记 `.edithere` 项目关联；组件页可选择登录启动、加入 PATH 与桌面快捷方式。新安装默认勾选登录启动和 PATH；升级时根据已有当前用户启动登记保留启动选项。安装完成后重新打开终端与 AI 工具，才能读取新 PATH。

Windows [免安装版压缩包](https://github.com/Inginnng/EditHere/releases/latest/download/EditHere-win-x64.zip)：本地构建产物形如 `dist/EditHere-<版本>-win-x64.zip`。完整解压并运行 `EditHere.exe`，保留同目录 DLL 和插件文件夹；无需安装 Qt、Python、Node 或 .NET。免安装版不自动添加 PATH，可用完整路径运行 CLI。

Windows 安装包尚未进行代码签名。请从本仓库 Releases 下载，并核对[程序包 SHA-256 校验和](https://github.com/Inginnng/EditHere/releases/latest/download/SHA256SUMS.txt)。 在下载目录打开 PowerShell，可用 `Get-FileHash .\EditHere-win-x64-setup.exe -Algorithm SHA256` 计算安装包的哈希，与文件内同名条目比较。

macOS 下载[通用版 DMG](https://github.com/Inginnng/EditHere/releases/latest/download/EditHere-macos-universal.dmg)，打开后将 `EditHere.app` 拖到其中的 **Applications** 入口。CLI 位于 `EditHere.app/Contents/MacOS/edithere-cli`。首次截图需屏幕录制权限，系统元素识别需辅助功能权限；尚未实机验收和 Apple 公证。

Windows 可通过系统“已安装的应用”或开始菜单中的卸载入口移除安装版。卸载仅移除随包安装的文件及其登记，保留用户设置与项目；无需为更新版本删除这些数据。

下文列出默认快捷键，可在设置中修改对应键盘操作。首次手动启动先显示使用引导；完成或跳过后不再自动显示。之后按 **Ctrl + Shift + 2** 或点击托盘图标截图。程序先关闭自身菜单并让系统托盘面板失去焦点，再采集画面。只有截图遮罩置顶，编辑窗口是普通应用窗口。

- 悬停智能选块；滚轮向上选择更大区域，向下选择更小区域。所有已识别、包含鼠标位置的框都可切换，无须互为父子。**滚轮选过的那一级会记住**：切到「整行 / 整张表」之后，再怎么移动鼠标、按方向键，选中的都还是那一级；想回到最小的一块就把滚轮往回滚，开始新一次截图时也会重新从最小的一块开始。**鼠标还在当前框里面时，框不会自己变小**——不会一进到里面的按钮或单元格就缩成那个小元素；把鼠标移出这个框，才会重新按指针下的元素来选。**方向键一格一格移动鼠标指针**（一次一格，只动被按的那个方向，在缩放屏上也是准确的一格），识别框高亮与放大镜跟着走，用来对准某一个像素；从进入截图到选区定下来，一直都能用。
- 单击选块或拖动画框，**松开鼠标后选区就定下来**，并在它**上方**出现截图工具条，在它**右侧**出现一列样式工具。进入批注是工具条上的一个动作（点「批注」或按回车），不再是松手的默认结果。
- 选区定下来之后仍可调整：在区域内拖动是移动，拖四角是缩放，在区域外重新拖动是重新框选；**方向键移动的是鼠标指针**（一次 1 像素，放大镜跟着走，用来对准某一个像素），`Shift` + 方向键从那一侧收缩 1 像素，`Ctrl` + 方向键向外扩展 1 像素。Esc 取消截图。

### 截图工具条

| 动作 | 默认快捷键 | 说明 |
| --- | --- | --- |
| 批注 | Enter | 进入批注编辑器 |
| 复制图像 | Ctrl + C | 把选区（含已选的圆角、边框、阴影）放进剪贴板 |
| 贴图（置顶） | Ctrl + T、Ctrl + 2、P | 把这一块钉在屏幕上，**贴回它原来所在的位置**，见下方说明 |
| 保存图片 | Ctrl + S | 另存为 PNG 或 JPEG |
| 文字识别 | Shift + C、T | 打开识别结果窗口，见下节 |
| 长截图（自动滚动） | L | 自动滚动并向下拼接，见下节 |
| 取色 | C | 进入取色，放大镜跟着鼠标走；再按 C 或 Ctrl + C 复制颜色值 |
| 历史截图上一张 / 下一张 | < / > | 不离开截图窗口就把更早的截图翻出来 |
| 恢复上次选区 | R | 直接采用最近用过的选区尺寸 |
| 更多选项 | H | 打开工具条菜单 |
| 取消 | Esc | 放弃本次截图 |

- 工具条左边显示选区的左上角坐标与「宽 × 高 px」，点它可以键入精确尺寸；锁定了比例时，高度由比例推出。
- 选区右侧的样式列是：**圆角**、**阴影 / 边框**、**重置**。圆角与阴影各打开一个小面板，用滑块调；阴影面板有「阴影 | 边框」两个页签和一个强度滑块（0–100），勾上「每次截图都设置」之后，这个样式会写进设置，以后每次截图都从它开始。**贴图只在工具条上出现一次**，不再在样式列里重复一个。
- 拖动选区时，指针旁会有一个**放大镜**，把指针附近放大十几倍。它放大的是**屏幕上看到的那一层**：蓝框、变暗的周围都跟着一起放大，框有多粗放大后就有多粗。面板里还给出像素坐标与 `RGB` / `HEX` / `HSV` / `HSL` 读数。选区定下来之后，只要鼠标还在选区内，放大镜与读数就一直都在，不必先进取色。
- 「更多」菜单里还有：固定比例（1:1、4:3、3:2、16:9、9:16、自定义如 `21:9`）、文字识别语言、截图历史（含上一张 / 下一张）、最近的选区。
- 圆角与边框在选区上**所见即所得**地预览；复制、保存、置顶、识别拿到的都是带上这些效果的成品图。阴影**默认开着**（中等强度），把强度滑块拖到 0 即关闭；它会把图片四周各扩出对应像素，且是平滑衰减的，越往外越淡，颜色用的是界面的强调色——就是选区那一圈蓝——不是黑色。阴影**只画在置顶的图片上**，截图窗口里不铺：调好强度后贴一次图就能看到效果。
- 最近 **20 张截图**与最近 **10 个选区**跨会话保留。截图时按 `H` 从最近 5 张里挑一张直接打开，按 `R` 恢复最近用过的选区尺寸。

**取色**：进入取色后放大镜跟着鼠标走，指到哪儿就读哪儿的颜色。面板里给出像素坐标、一个色块，以及 `RGB`、`HEX`、`HSV`、`HSL` 四种写法；`Shift` 在这四种之间循环，颜色最深的那一种就是会被复制的那一种。按 `C` 或 `Ctrl + C` 复制颜色值，点一下鼠标也复制并结束取色，`Esc` 或右键结束取色。

**置顶窗口**可以同时钉多张，默认就落在刚才截图的那个位置。

- **移动**：在图片中间按住拖动。
- **缩放**：鼠标移到图片**边缘或四角**，光标会变成对应的缩放光标，按住拖动即可放大缩小；滚轮也可缩放（10%–400%），按 `0` 适应屏幕。两种方式共用同一个缩放比例，拖完之后接着滚轮不会跳回去。
- 图片四周常驻一圈**蓝色边框**，它既是"从哪里开始到哪里结束"的说明，也是可以拖动的边缘。
- `Ctrl + C` 复制；**双击或 `Esc` 关闭**。
- **右键菜单**：第一项是**批注**（把这张图交给编辑器，阴影不计入画布），其后是复制图像、保存图片、文字识别、**旋转**（向左/向右 90°、水平翻转、垂直翻转）、**透明度**（100% / 75% / 50% / 25% / 10%）、**阴影**（可随时开关）、缩放（适应屏幕 / 原始大小 / 回到截图位置）与关闭。从别处直接贴进来的图没有可开关的阴影，该项会置灰。
- 带阴影的图会把阴影一起带过去，四周透明的那一圈透出桌面。

### 文字识别

- 识别结果在独立窗口里**逐行**列出，点某一行会高亮它在原图上对应的位置，便于发现读错的地方；可以复制全部、只复制选中行、或换个语言重新识别。
- 识别语言在 **设置 → 外观 → 文字识别语言** 里选（跟随系统 / 简体中文 / English），也可以在截图工具条的菜单里就地切换，选择会被记住。
- 识别用的是**系统自带能力，不联网、不上传、不新增依赖**：Windows 用系统自带的 OCR 引擎，macOS 用 Vision。系统没装对应语言的识别包时，窗口里会给出该到哪里添加的提示。
- 图片比识别引擎的上限更大时，会按条带切分后逐段识别，再把行框还原到整张图的坐标，所以大图不会丢行也不会错位。

### 长截图（自动滚动）

- 在选区内向被截的页面发送滚动，逐步抓帧，按相邻两帧的重叠部分竖向拼接；画面不再变化即认为已到底，最多 60 帧、最高 20000 像素。
- **选区里有固定不动的部分也没关系**：顶部导航条、底部播放控制条、状态栏这类"滚动时不动的横条"会被自动认出来，拼接时排除掉，最后各只保留一条，不会重复出现，也不会因为它们在而拼不上。
- **抓帧前会等页面停稳**：滚动之后先看一眼，隔一小段时间再看一眼，两次一样才认为页面停了；不一致就继续等（最多 4 次，所以有视频或动画的页面也不会一直卡住）。
- **一次没抓到新内容不算到底**：会再滚一轮确认。懒加载的图片、或者还没反应过来滚轮的窗口，都能靠这一下补上；两轮都没有新内容才结束。
- 页面里有轻微动效（光标闪烁、加载动画）时，匹配会依次放宽到能对上的档位而不是整张作废；用到放宽档位时托盘的提示会写明"拼接有偏差"，此时结果仍可用，只是接缝处可能有一两像素的错位。
- 达到帧数上限、找不到屏幕、选区跑到屏幕外等情况会明确说明原因，而不是给出一张残图。
- 拼接完成后结果直接进入批注编辑器，可以像普通截图一样批注、保存或导出。
- 想得到最好的结果：把固定的页头页脚留在选区里也没问题，但把**选区对准要截的那一栏内容**、别把悬浮的动图或视频框进来，会更准。

以下是选区交给批注编辑器之后的说明。

- 批注栏从一开始就固定预留。点编号或移动箭头，在右侧直接编辑，离开输入框自动保存；右上角加号可添加全局意见。框选松开立即在侧栏输入批注，并保留手动区域供组件调整。

- 空白处滚轮或 Ctrl+滚轮以鼠标指向的位置缩放整张图片；按住鼠标中键可自由平移，图片比窗口小时也能拖动，并可越过图片四边，普通批注与大爆炸模式一致。Ctrl+0 适应窗口。普通窗口下拖动顶栏，或按住空格/Alt 拖动画面，可移动窗口。
- 调整工具可移动或缩放批注框；单击编号编辑文字。顶部眼睛按钮隐藏画面标记，保留右侧批注。Ctrl+Z 撤销，Ctrl+Y 重做，Delete 删除。
- 空白处滚轮或 Ctrl+滚轮以鼠标指向的位置缩放整张图片；按住鼠标中键可自由平移，图片比窗口小时也能拖动，并可越过图片四边，普通批注与大爆炸模式一致。Ctrl+0 适应窗口。普通窗口下拖动顶栏，或按住空格/Alt 拖动画面，可移动窗口。
- 支持打开、拖入或粘贴 PNG/JPEG/WebP/BMP，以及重新打开 `.edithere` 项目或反馈 JSON。
- 关闭当前截图会提示保存未存修改，随后释放截图和切块缓存；程序仍驻留托盘。

Mac 编辑快捷键使用 Command，重做为 Command + Shift + Z，截图为 Command + Shift + 2。Mac 尚未实机验证。

## 使用引导与开机自启

- 首次手动启动在真实编辑窗口展示六步引导，可随时跳过；没有截图时使用示例，有截图时保留原内容。右上角 **?** 和设置底部的 **使用引导** 均可从头开始。引导可前后翻页，Esc 只退出引导。
- 引导状态与设置偏好分开保存，恢复默认设置不会让引导反复出现。从设置重看引导会关闭设置窗口，不保存尚未应用的修改。
- 在 **设置 → 默认行为 → 开机时启动 EditHere（改这里）** 勾选并保存后开启，取消勾选再保存即可关闭。Windows 新安装器默认勾选登录启动，可在安装时取消；免安装版未登记自启时默认关闭。登录系统后仅驻留托盘，不自动截图；“启动后立即截图”只用于普通手动启动。
- Windows 使用当前用户的启动项，无需管理员权限。免安装版启用后请保留程序所在文件夹；移动程序或从旧版升级后，保持勾选并保存即可更新启动路径。如果 Windows 已禁用该启动项，程序会提示到系统启动应用设置中手动恢复，不会强行修改系统禁用状态。Mac 使用系统登录项，若系统要求批准会明确提示；Mac 仍未实机验收。

## 与 AI 配合使用

你可以手动复制 JSON，也可以让接入 CLI 的 AI 发起标注会话。后一种方式中，AI 打开图片，你添加批注或调整组件，最后点击顶部 **“完成并返回 AI”**；CLI 此时才导出本轮反馈并返回成功。点击“取消”或等待超时不提交反馈，编辑器保留当前文档。连接中断时结果可能不明，需核查本轮是否已经完成，不能直接重复发起会话。

每轮反馈使用新的输出文件，AI 只读取本轮明确提交的结果，不能将之前的文件当作新意见。配套 skill 的安装、命令和示例见 [AI 与命令行](AGENT-CLI.md)。

## 设置

右键任务栏右下角的 EditHere 托盘图标，选择“设置”。窗口包含“快捷键”“外观”“默认行为”“工具栏”和“关于与更新”。点击“保存”应用设置；快捷键和外观立即生效，默认工具/缩放用于下一张图片，启动行为用于下次启动。“取消”不改变当前配置。

可配置 21 项快捷键：截图为全局快捷键，在其他应用中也能触发；其余在 EditHere 编辑窗口中使用。点击输入框后按下新的组合键，清空可停用对应快捷键。“恢复默认”会重置当前设置草稿，仍需保存才生效。重复分配、系统占用或保存失败会显示原因并保留原有配置。

以下为 Windows 默认键位；Mac 常用编辑组合使用 Command，重做为 Command + Shift + Z，尚待实机验证。

| 应用内 | 打开图片或项目 | Ctrl + O |
| 应用内 | 粘贴图片 | Ctrl + V |

外观支持**跟随系统、亮色、暗色**，默认为跟随系统。切换后，编辑器、批注栏、组件侧栏、菜单和设置窗口统一更新；原图与导出图片的原始像素不受主题影响。

设置保存在当前用户的 Qt `AppConfigLocation/settings.ini`，关闭程序后仍保留。Windows 默认位置为 `%LOCALAPPDATA%/EditHere/EditHere/settings.ini`；Mac 由系统配置目录决定。

## 大爆炸

点击顶部“大爆炸”按钮，按钮变色，并播放从右上向左下扫过的虹彩波浪。组件直接在**当前窗口**内调整。

首次进入会按识别框切块；再次点击按钮关闭模式时，画面保留调整结果，切块缓存继续保留。重新开启会使用同一套切块及调整数据，不会重新切分；关闭当前截图后才清除缓存。

大爆炸开启时，右侧始终保留批注；点标注工具可在结果上添加意见，编号和移动箭头可直接点击编辑。智能工具用于选块和调整，框选用于补充手动区域；选中组件后可从右侧添加批注。组件调整区固定在侧栏底部，批注列表独立滚动。附着在组件上的批注随组件移动、缩放，编辑结果和批注使用同一套画布坐标。

| 操作 | 行为 |
| --- | --- |
| 未选中时悬停并滚轮 | 遍历包含鼠标的全部候选范围 |
| 单击候选范围 | 选中组件或组件组 |
| 拖动已选区域内部 | 移动组件 |
| 拖动边缘中点 | 改变宽度或高度 |
| 拖动角点 | 等比例缩放，无需 Shift |
| 指向已选组件时滚轮 | 等比例放大或缩小组件；指向空白处缩放整图 |
| 右侧 X、Y、宽度、高度、缩放 | 精确设置像素位置、尺寸和比例 |
| 方向键 | 移动 1 px |
| 右键、Esc 或“取消选择” | 返回悬停选块 |
| 底部“框选”后画框 | 添加可操作区域，爆炸前后均可使用 |
| Ctrl+滚轮 | 缩放视图 |

选择大框时，内部组件一起移动、缩放，并保留相对布局。支持撤销和重做。移动后原位置留空，以透明棋盘格显示；不补背景、不恢复被遮挡的内容。调整限制在原图大小的画布内。

## 精简 JSON

复制 JSON 与导出 JSON 采用同一种精简结构。导出窗口默认勾选包含原图；需要单独发送图片时，可取消勾选以缩短 JSON。Ctrl+S 保存 `.edithere` 完整项目，始终内嵌原图及切块缓存，供以后继续编辑；不会把完整项目结构塞进给 AI 的反馈 JSON。

| 字段 | 含义 |
| --- | --- |
| `image` | 可选的调整前图片 data URL（PNG 或压缩 JPEG）；尺寸保持不变，压缩 JPEG 会损失部分细节 |
| `annotationSpace` | 固定为 `"result"`，表示批注坐标对应当前调整后的画面 |
| `annotations` | 文字 `text`，可带 `point` / `rectangle` 定位；全局意见仅含 `text`，移动箭头意见带对应变化的零基序号 `change` |
| `changes` | 仅记录位置或尺寸发生变化的区域：`from` 为原图坐标，`to` 为最终坐标 |

没有变化的组件不导出；不输出完整切片清单、组件组引用、哈希或时间戳。原图 Base64 会增加文件体积，这是将图片放进单个 JSON 的数据开销，与组件数量无关。

坐标以画布左上角为原点，单位为图像像素，与窗口位置和视图缩放无关。框使用 `x1/y1/x2/y2` 两个端点；右下边界不包含自身，宽高为 `x2-x1`、`y2-y1`。批注坐标为整数，布局变化坐标可含小数。

以下示例省略可选的 `image` 字段，展示一个区域向右下方移动后的批注：

```json
{
  "annotationSpace": "result",
  "annotations": [
    {"point": {"x": 240, "y": 180}, "text": "这里改为蓝色"},
    {"rectangle": {"x1": 200, "y1": 140, "x2": 400, "y2": 240}, "text": "增加圆角"}
  ],
  "changes": [
    {
      "from": {"x1": 100, "y1": 100, "x2": 300, "y2": 200},
      "to": {"x1": 200, "y1": 140, "x2": 400, "y2": 240}
    }
  ]
}
```

还原结果时，先从原图提取所有 `from` 区域并将原位置留空，再按 `changes` 数组顺序绘制到 `to`；最后在结果上解释或绘制批注。未移动区域保持原样。0.8 继续使用 0.7 JSON 格式，由 `schema/feedback-v0.7.schema.json` 定义。

| 格式 | 原图 | 批注坐标 | 布局信息 |
| --- | --- | --- | --- |
| 0.5 及以前的 v1/v1.1/v2 项目 | `capture.pngBase64` 可内嵌，或引用外部 PNG | 原图 | v2 保存全部切片、分组及原始/目标坐标 |
| 0.6 精简反馈 | 外部同名 PNG | 原图 | 仅变化的 `from/to` |
| 0.7 / 0.8 当前反馈 | `image` 可内嵌，界面默认包含 | 调整后的画面 | 仅变化的 `from/to` |
| 3.0.0 `.edithere` 项目 | 始终内嵌原图 | 调整后的画面 | 完整切块缓存和当前编辑状态 |

应用不再打开旧版项目及 0.6 精简反馈，旧批注不再转换到调整结果的位置。取消包含原图时，重新打开需要配套的同名原图 PNG。`.edithere` 项目保存完整切块及编辑状态（`schemaVersion: "3.0.0"`），重新打开直接恢复。关闭截图会释放内存缓存。重新打开精简反馈时，从原图和变化重建布局。

## 识别与平台边界

图片识别完全在本机运行，采用颜色连通区域、边缘聚合及横竖线网格分析，不需要网络、账号或模型下载。它能识别卡片、图片和较清晰的轮廓，但不是 OCR 或语义物体识别，不能保证每个候选都是用户理解的组件；可手动画框补充。

Windows 使用 UI Automation、Mac 使用 Accessibility 读取目标应用公开的元素边界。探测在独立短进程中运行，超时会停止。识别信息不包含代码仓库里的 DOM、组件名或源码位置；网页 DOM 标注仍是独立方向。

当前每次截取一块显示器内的区域，不跨屏拼接。混合缩放、多屏布局、托盘展开面板、受保护画面及不同浏览器仍需要更多设备验证。

| 平台 | 状态 |
| --- | --- |
| Windows x64 | 在 Windows 11 开发与测试；最低构建目标为 Windows 10 1809+，未逐一测试旧系统 |
| Windows 截图与 UI Automation | 已用本程序真实测试窗口校验像素、物理尺寸和按钮边界 |
| Windows 托盘面板与多屏 | 仍需更多真实环境验收 |
| Mac | GitHub macOS 构建与自动测试已通过，生成临时签名 DMG；**尚未实机验收** |
| Mac ARM / Intel | 已编译 arm64 + x86_64 通用程序，CI 在 Apple 芯片环境运行测试；Intel 尚未运行验收 |

Mac 目标为 macOS 14+，使用 ScreenCaptureKit。首次截图需屏幕录制授权；系统元素识别需辅助功能授权，托盘菜单提供入口。普通图片导入无需这些权限。目前没有可用的 Mac 测试设备。公开 Mac 发行还需产品所有者的 Apple 签名和公证。
