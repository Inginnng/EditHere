Help2Design Native 0.4.0

Windows：解压完整文件夹，双击 Help2Design.exe 即可截图。
请保留同目录 DLL、platforms、imageformats、licenses 等文件。
Mac：当前源码已提供适配和构建脚本；本次 Windows 交付不包含经过验证的 Mac 应用。

截图
• Windows 快捷键 Ctrl + Shift + 2；Mac 预定为 Command + Shift + 2。
• 屏幕变暗后，移动鼠标智能选块；滚轮向上选择更大的包含区域，向下选择更小区域。
• 也可直接拖拽框选，选择后拖动边缘调整大小。
• Enter 开始批注；Ctrl+C 直接复制截图；右键返回；Esc 取消。
• 同时连接多屏时，每次选取其中一块屏幕内的区域。

批注
• 智能、点、框、调整：底部四个工具。
• 单击或画框后输入修改意见，编号和文字同步显示在右侧。
• 调整模式可移动标注、拖动框的八个手柄，双击编辑文字。
• 滚轮切换智能选块层级；Ctrl+滚轮缩放；中键切换原尺寸/适应窗口。
• 拖动顶栏，或按住空格/Alt 拖动画面，移动整个批注窗口。
• Ctrl+Z 撤销；Ctrl+Y 重做；Delete 删除选中批注；Ctrl+S 保存可恢复的项目。
• Mac 编辑快捷键用 Command 代替 Ctrl。

导出
• 点击“导出 JSON”，可复制标准 JSON，或保存 JSON、原图和带批注预览图。
• JSON 的所有标注坐标均为原图像素，左上角为原点。
• 矩形的 x2/y2 是右下边界，不包含该边界上的像素。
• “包含原图数据”开启后，单个 JSON 可以重新导入恢复。
• 默认只复制文字 JSON 时，请将对应原图一并交给 AI。
• 关闭窗口后程序留在托盘，仍保留当前批注；彻底退出会提示保存未存内容。

识别完全在本机运行，不调用网络 AI。
图片算法识别的是色块和轮廓，不理解物体的语义。
系统元素识别取决于目标应用是否公开辅助功能信息；无法读取时可继续手动框选。
