Help2Design Native 0.5.0

Windows：解压完整文件夹，双击 Help2Design.exe 即可截图。
请保留同目录 DLL、platforms、imageformats、licenses 等文件。
Mac：源码已提供适配和构建脚本，目前没有 Mac 测试设备；未编译、未实机验证，本次交付不包含 Mac 应用。

截图
• Windows 快捷键 Ctrl + Shift + 2；Mac 对应 Command + Shift + 2，尚待实机验证。
• 点击托盘截图后，程序先收起菜单和系统托盘展开面板，再采集画面。
• 屏幕变暗后移动鼠标智能选块：滚轮向上选大框，向下选小框。
• 所有已检测到、包含鼠标位置的框都可切换，不限于相邻父子框。例如单格 3、行 34、区域 3456、整个表格 123456。
• 也可直接拖拽框选；选区确认前可以移动或调整大小。
• Enter 开始批注；Ctrl+C 直接复制截图；右键返回；Esc 取消。
• 多屏时每次选取其中一块屏幕内的区域。只有截图遮罩置顶，编辑窗口不置顶。

批注
• 底部提供智能、点、框、调整四个工具。
• 单击或画框后输入修改意见，编号和文字同步显示在右侧。
• 调整模式可移动标注、拖动框的八个手柄，双击编辑文字。
• Ctrl+滚轮缩放视图；中键切换原尺寸/适应窗口。
• 拖动顶栏，或按住空格/Alt 拖动画面，移动整个批注窗口。
• Ctrl+Z 撤销；Ctrl+Y 重做；Delete 删除选中批注；Ctrl+S 保存项目。
• Mac 编辑快捷键用 Command，重做为 Command + Shift + Z。

大爆炸
• 点击顶部“大爆炸”，按识别区域调整组件；大范围可作为组件组整体操作。
• 未选中时：鼠标悬停并滚动，切换包含该位置的全部候选范围；单击确认选择。
• 选中后：拖动内部移动；拖边缘改变宽或高；拖角点保持比例缩放，不需要 Shift。
• 选中后滚动滚轮会等比例缩放组件；Ctrl+滚轮只缩放视图。
• 右侧可以精确设置 X、Y、宽度、高度和等比缩放百分比。百分比以本次选中时的尺寸为 100%。
• 方向键每次移动 1 px；右键、Esc 或“取消选择”返回悬停选块。
• “手动分块”后拖动画框，可在当前布局中添加操作区域，包括已经移动、缩放过的组件。
• 移动整个组件组时，内部组件的相对布局随之变化。
• 原位置留空为透明区域，以棋盘格显示；不恢复原来被遮挡的内容，不自动补背景。
• “完成调整”返回效果预览；“取消”放弃本次进入后的调整。支持撤销、重做。
• 点击“批注原图”继续添加批注，点击“查看调整效果”切回布局预览；预览上双击可继续大爆炸。
• 批注始终对应原图，调整效果单独预览。组件移动、缩放均限制在原图大小的画布内。

保存与导出
• Ctrl+S 保存原图、全部批注及组件布局，之后可重新打开项目 JSON。
• 点击“导出 JSON”复制文本，或保存 JSON、原图、带批注的原图预览；有布局时另附调整效果 PNG。
• 所有坐标以左上角为原点，使用图像像素，与窗口位置和视图缩放无关。
• 点为 x/y，框为 x1/y1/x2/y2；x2/y2 是不包含自身的右下边界。
• 有布局时导出 JSON 2.0：source 记录原始切片坐标，destination 记录目标画布坐标，pieceIds 记录组件组。
• 布局坐标可含小数；原始 PNG 和哈希不因布局调整而改变。
• 无布局仍使用 JSON 1.0，含 Mac 辅助功能来源时为 1.1。此版本可打开旧桌面/Web 项目；旧应用不能恢复新布局。
• 开启“包含原图数据”后，单个 JSON 可导入还原；否则需要将同目录原图一起保留，并与 JSON 一并交给 AI。
• 关闭窗口后程序留在托盘，仍保留当前内容；彻底退出会提示保存未存修改。

识别完全在本机运行，不调用网络 AI。图片算法识别色块和轮廓，不理解物体语义，也不能保证每个组件都被正确划分；可以手动分块补充。
系统元素识别取决于目标应用公开的辅助功能信息。Windows 浏览器、托盘展开面板和多屏组合仍需要更多实际环境验证。
