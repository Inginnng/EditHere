HelpDesign（版本见同目录 version.txt）

Windows：先从托盘退出旧版，完整解压后运行 HelpDesign.exe。
保留同目录 DLL、platforms、imageformats、licenses 等文件；无需额外安装开发环境。
Mac：请使用单独的 .app/.dmg 版本。首次截图需屏幕录制授权，元素识别需辅助功能授权；尚未完成实机验收。

设置
• 右键任务栏右下角的 HelpDesign 托盘图标，选择“设置”。
• “快捷键”可配置 17 项操作：截图为全局快捷键，其余在应用编辑窗口内使用。
• 点击输入框后按下新的组合键；清空即停用。“恢复默认”后仍需点击“保存”。
• 默认全局截图为 Ctrl+Shift+2；打开 Ctrl+O、粘贴 Ctrl+V、保存 Ctrl+S、导出 Ctrl+E、复制 Ctrl+C。
• 撤销 Ctrl+Z、重做 Ctrl+Y、适应窗口 Ctrl+0、删除 Delete、取消操作或关闭截图 Esc。
• 智能选块 B、点标注 P、框选标注 R、调整批注 V、切换大爆炸 E、移动组件 M。
• 相同组合键不能分配给多个操作；系统占用或保存失败时会显示原因并保留原配置。
• “外观”支持跟随系统、亮色和暗色，默认跟随系统；主题不改变截图原始像素。
• 修改后保存立即生效，无需重启；取消不改变当前配置。
• 设置保存在当前用户 AppConfigLocation/settings.ini，程序退出后仍保留。
• Windows 默认为 %LOCALAPPDATA%/HelpDesign/HelpDesign/settings.ini；Mac 由系统配置目录决定。
• 下文列出的键位均为默认值，修改后以设置窗口和界面提示为准。

截图
• Ctrl + Shift + 2 或点击托盘图标截图；Mac 对应 Command + Shift + 2，尚待实测。
• 屏幕变暗后，移动鼠标智能选块；滚轮向上选大框，向下选小框。
• 所有已识别且包含鼠标位置的框均可切换，包括单格、行、整表。
• 单击选块或拖拽框选，松开鼠标立即进入批注，无需再次确认。
• Esc 取消；悬停选区时可用 Ctrl+C 直接复制截图。
• 每次选取一块屏幕内的区域。只有截图遮罩置顶，编辑窗口不置顶。

批注
• 右侧从一开始预留批注位置，添加批注不会重新挤压整个布局。
• 单击或画框后输入意见，编号与文字显示在右侧。
• 调整组件后直接在当前结果上批注；不需要切换回原图。
• 调整模式可移动标注、改变批注框大小，双击编辑文字。
• Ctrl+滚轮缩放视图；中键切换原尺寸/适应窗口。
• 拖动顶栏，或按住空格/Alt 拖动画面，可移动窗口。
• Ctrl+Z 撤销，Ctrl+Y 重做，Delete 删除，Ctrl+S 保存。
• Mac 对应 Command，重做为 Command + Shift + Z。

大爆炸
• 点击“大爆炸”，按钮变色，虹彩波浪从右上向左下扫过；直接在当前窗口调整。
• 第一次开启时切块；关闭模式保留调整后的画面与切块缓存。
• 再次开启沿用当前截图的原有切块，不会重新切分；关闭当前截图后才清除缓存。
• 大爆炸开启时仍可选择智能、点或框工具添加批注；点击“移动组件”返回组件操作。
• 附着在组件上的批注随组件移动、缩放，批注坐标对应当前调整后的画面。
• 未选中时悬停并滚轮，切换包含鼠标的全部候选范围；单击选中组件或组件组。
• 选中后拖动内部移动；拖边改变宽高；拖角等比缩放，无需 Shift。
• 选中后滚轮等比例缩放；Ctrl+滚轮只缩放视图。
• 右侧可精确设置 X、Y、宽度、高度和缩放比例。
• 方向键移动 1 px；右键、Esc 或“取消选择”返回悬停选块。
• “手动分块”后画框，可添加操作区域；组件组整体调整时保留内部相对位置。
• 支持撤销、重做。移开后的原位置透明留空，不补背景，不还原被遮挡内容。
• 调整限制在原图大小的画布内。

保存与导出
• 导出窗口默认包含原图：image 字段是 data:image/png;base64,...，保存调整前的完整截图。
• 可取消包含原图，以缩短 JSON；此时需配套发送同名原图 PNG。
• Ctrl+S 始终保存内嵌原图的 JSON，单个文件即可重新打开。
• annotationSpace 固定为 result：annotations 的点或框坐标，对应当前调整后的画面。
• 每条 annotations 只包含 point 或 rectangle，以及批注文字 text。
• changes 只导出移动或缩放过的区域；from 是原始框，to 是最终框。
• 未变化组件不导出，不包含完整切片清单、组件组引用、哈希或时间戳。
• 坐标以画布左上角为原点，使用图像像素；点为 x/y，框为 x1/y1/x2/y2。
• x2/y2 是不包含自身的右下边界，布局坐标可以含小数。
• 还原结果时先提取所有 from 并清空原位置，再按 changes 顺序绘制到 to，最后叠加批注。
• 原图 Base64 会增加文件体积，这是单个 JSON 内嵌图片的正常数据开销。
• 0.8 沿用 0.7 JSON 格式，见 schema/feedback-v0.7.schema.json；旧版 v1/v1.1/v2 和 0.6 精简反馈仍可打开。
• 旧版原图坐标批注会转换到结果位置，界面不再生成包含全部切块的长 JSON。
• 关闭当前截图会提示保存未存修改，然后释放原图及切块缓存；程序仍驻留托盘。
• 重新打开保存的反馈时，从原图与变化信息重建布局。

识别完全在本机运行，不使用网络 AI。算法识别色块和轮廓，不能保证每个组件都被正确划分，可手动分块补充。
系统元素识别取决于目标应用公开的辅助功能信息；托盘展开面板、多屏及不同浏览器仍需更多环境验证。
