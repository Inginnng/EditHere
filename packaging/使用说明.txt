HelpDesign（版本见同目录 version.txt）

Windows：先从托盘退出旧版，完整解压后运行 HelpDesign.exe。
保留同目录 DLL、platforms、imageformats、licenses 等文件；无需额外安装开发环境。
Mac：请使用单独的 .app/.dmg 版本。首次截图需屏幕录制授权，元素识别需辅助功能授权；尚未完成实机验收。

使用引导
• 首次手动启动自动显示引导，可上一页、下一步或跳过；Esc 只退出引导。
• 点击编辑窗口右上角“?”或设置底部“使用引导”可从头再看。
• 引导不会替换已有截图或丢失批注；从设置重新查看时不保存尚未应用的设置。

设置
• 点击主界面顶栏“设置”，或右键任务栏右下角的 HelpDesign 托盘图标选择“设置”；更多菜单与画布右键也有入口。
• “快捷键”可配置 21 项操作：截图为全局快捷键，其余在应用编辑窗口内使用。
• 点击输入框后按下新的组合键；清空即停用。“恢复默认”后仍需点击“保存”。
• 默认全局截图为 Ctrl+Shift+2；打开 Ctrl+O、粘贴 Ctrl+V、保存 Ctrl+S、查看 JSON Ctrl+E、复制 Ctrl+C。
• 撤销 Ctrl+Z、重做 Ctrl+Y、适应窗口 Ctrl+0、删除 Delete、取消操作或关闭截图 Esc。
• 智能选块 B、点标注 P、框选标注 R、调整批注 V、切换大爆炸 E、调整组件 M。
• 相同组合键不能分配给多个操作；系统占用或保存失败时会显示原因并保留原配置。
• “外观”支持跟随系统、亮色和暗色，默认跟随系统；主题不改变截图原始像素。
• 修改后保存立即生效，无需重启；取消不改变当前配置。
• “默认行为”可选择“开机时启动 HelpDesign”，默认关闭，勾选并保存才生效。
• 开机登录时只驻留托盘，不弹出截图或引导；首次手动使用再显示引导。
• 启用自启后请保留程序所在文件夹，移动程序后需重新设置。
• 设置保存在当前用户 AppConfigLocation/settings.ini，程序退出后仍保留。
• Windows 默认为 %LOCALAPPDATA%/HelpDesign/HelpDesign/settings.ini；Mac 由系统配置目录决定。
• 下文列出的键位均为默认值，修改后以设置窗口和界面提示为准。

截图
• Ctrl + Shift + 2 或点击托盘图标截图；Mac 对应 Command + Shift + 2，尚待实测。
• 屏幕变暗后，移动鼠标智能选块；滚轮向上选大框，向下选小框。
• 所有已识别且包含鼠标位置的框均可切换，包括单格、行、整表。
• 单击选块或拖拽框选，松开鼠标立即进入批注，无需再次确认。
• Esc 取消；悬停选区时可用 Ctrl+C 直接复制截图。
• 每次选取一块屏幕内的区域。只有截图遮罩置顶，编辑窗口不置顶。

批注
• 顶栏“最小化”可将编辑窗口缩到任务栏，恢复后继续当前截图。
• 最小化与关闭之间是“全屏”，再次点击退出并恢复原窗口；默认 Esc 优先退出引导或批注输入，再退出全屏。
• 右侧从一开始预留批注位置，添加批注不会重新挤压整个布局。
• 点编号或移动箭头，在右侧直接编辑，离开输入框自动保存；右上角加号添加全局意见。
• 整体移动大块只显示一条轨迹；之后单独移动里面的小块，再显示从小块原图位置到最终位置的轨迹。同一区域反复调整会更新原有轨迹。
• 未批注的箭头没有数字，直接点击箭头即可添加说明；添加后编号与右侧批注一致，复制或保存带批注图片也保持一致。可编辑项目保留区域轨迹关系，反馈 JSON 仍只包含原图、批注和变化。
• 顶部眼睛按钮隐藏画面标记，保留右侧批注；底部收起按钮只折叠侧栏。
• 超过两行的批注可展开全文；收起显示两行并渐隐第二行，不再使用内部滚动条。
• 添加或编辑下一条时自动收起前一条；新批注会自动滚入视野。
• 调整组件后直接在当前结果上批注；不需要切换回原图。
• 调整模式可移动、缩放批注框；单击编号编辑文字。
• 空白处滚轮或 Ctrl+滚轮缩放整张图片；按住中键拖动可平移查看放大后的截图，普通批注和大爆炸都支持；Ctrl+0 适应窗口。
• 普通窗口下拖动顶栏，或按住空格/Alt 拖动画面，可移动窗口。
• Ctrl+Z 撤销，Ctrl+Y 重做，Delete 删除，Ctrl+S 保存。
• Mac 对应 Command，重做为 Command + Shift + Z。

大爆炸
• 点击“大爆炸”，按钮变色，柔和虹彩光浪从右上向左下扫过，边缘辉光随之移动；直接在当前窗口调整。
• 第一次开启时切块；关闭模式保留调整后的画面与切块缓存。
• 再次开启沿用当前截图的原有切块，不会重新切分；关闭当前截图后才清除缓存。
• 大爆炸的调整面板与批注同时显示。智能工具调整组件，点工具添加批注；编号和移动箭头可直接点击编辑。
• 附着在组件上的批注随组件移动、缩放，批注坐标对应当前调整后的画面。
• 未选中时悬停并滚轮，切换包含鼠标的全部候选范围；单击选中组件或组件组。
• 选中后拖动内部移动；拖边改变宽高；拖角等比缩放，无需 Shift。
• 指向选中组件时滚轮等比例缩放；指向空白处或 Ctrl+滚轮缩放整图。
• 右侧可精确设置 X、Y、宽度、高度和缩放比例。
• 方向键移动 1 px；右键、Esc 或“取消选择”返回悬停选块。
• 底部“框选”松开后直接在侧栏输入批注，并保留操作区域；爆炸之前也可使用。
• 组件调整区固定在侧栏底部，与批注列表用细线分隔；“显示分解框”控制候选框显示。
• 支持撤销、重做。移开后的原位置透明留空，不补背景，不还原被遮挡内容。
• 调整限制在原图大小的画布内。

保存与导出
• 导出窗口默认包含原图：image 字段是 data:image/png;base64,...，保存调整前的完整截图。
• 可取消包含原图，以缩短 JSON；此时需配套发送同名原图 PNG。
• Ctrl+S 保存 .helpdesign 完整项目，内嵌原图、批注与切块缓存，重新打开继续编辑。
• 蓝色大按钮直接复制 JSON，小图标打开“查看 JSON”。复制默认包含原图，可在默认设置修改。
• 保存项目、保存图片、查看 JSON、复制 JSON、复制带批注图片、重新截图、适应图片，可在“设置 → 工具栏”配置。
• 未勾选或窗口内放不下的操作会收进“…”更多菜单；常驻工具保留在分隔线左侧。
• 首次保存时登记当前用户的 .helpdesign 文件关联；如已有其他默认程序，则不覆盖。
• annotationSpace 固定为 result：annotations 的点或框坐标，对应当前调整后的画面。
• annotations 包含 text，区域意见带 point 或 rectangle；全局意见只含 text，移动箭头意见带对应 changes 的零基序号 change。
• changes 只导出移动或缩放过的区域；from 是原始框，to 是最终框。
• 未变化组件不导出，不包含完整切片清单、组件组引用、哈希或时间戳。
• 坐标以画布左上角为原点，使用图像像素；点为 x/y，框为 x1/y1/x2/y2。
• x2/y2 是不包含自身的右下边界，布局坐标可以含小数。
• 还原结果时先提取所有 from 并清空原位置，再按 changes 顺序绘制到 to，最后叠加批注。
• 原图 Base64 会增加文件体积，这是单个 JSON 内嵌图片的正常数据开销。
• 0.8 沿用 0.7 JSON 格式，见 schema/feedback-v0.7.schema.json；旧版 v1/v1.1/v2 和 0.6 精简反馈仍可打开。
• 旧版原图坐标批注会转换到结果位置，界面不再生成包含全部切块的长 JSON。
• 关闭当前截图会提示保存未存修改，然后释放原图及切块缓存；程序仍驻留托盘。
• 重新打开精简反馈时，从原图与变化重建布局；.helpdesign 项目则恢复保存的完整切块。

识别完全在本机运行，不使用网络 AI。算法识别色块和轮廓，不能保证每个组件都被正确划分，可手动分块补充。
系统元素识别取决于目标应用公开的辅助功能信息；托盘展开面板、多屏及不同浏览器仍需更多环境验证。

表格识别
• 有线表格增加原始分辨率检测，支持浅灰细线、暗色背景、短断线与合并单元格。
• 滚轮可切换已识别的单元格、行、列和整表；过密场景优先保留整表与行列。
• 无边框或模糊表格仍可能漏检，可手动框选；不提供图片内部语义物体分割。

默认设置与版本检查（0.8.3）
• 托盘右键“设置” → “默认行为”：启动后立即截图、默认标注工具、打开图片时适应窗口、导出 JSON 默认包含原图。
• 关闭启动截图后只驻留托盘。工具和初始缩放用于下一张图片，不改变正在编辑的内容。
• 保存项目始终包含原图。“恢复默认”需点击保存才生效；取消不改变配置。
• 托盘右键“检查更新”，或“设置” → “关于与更新”。只检查正式版，跳转发布页手动下载。
• 启动检查默认关闭；开启后只在有新版本时提醒，不自动下载、安装或上传截图。
• 当前仓库为私有，电脑若已安装 GitHub CLI 并登录有权限账号，可直接读取发行信息；否则请在浏览器登录后查看发布页。应用不保存访问令牌。
• 无权限、暂无发行版、网络错误或超时都会明确显示，不能据此判断已是最新版。
