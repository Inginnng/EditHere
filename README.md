# Help2Design Capture

Windows 截图批注工具，桌面版 0.2.0。截图、点选或框选目标、填写修改意见，最后导出带原图像素坐标的 JSON。网页 DOM 编辑工具留作独立模块。

## 运行

解压便携包，双击 `Help2Design.Capture.exe`。源码目录中的已编译程序位于 `bin/Help2Design.Capture.exe`，也可以双击 `Run.cmd`。

运行环境：Windows 10 / 11 x64、.NET Framework 4.8 或更高版本。当前电脑已具备运行环境。无需安装 Node、Python、浏览器扩展或配置 AI API。

启动后直接灰屏截图，没有首页。取消后驻留托盘；再次点击托盘图标或按 Ctrl+Alt+2 截图。源码中可用 `bin/Help2Design.Capture.exe --demo` 打开示例。

## 使用

1. 启动程序或按 Ctrl+Alt+2，直接进入灰屏选区；单击吸附，或拖动框选。滚轮向上选择更大区域，向下选择更小区域。选区边缘可拖动缩放，内部可拖动移动。
2. 点击「开始批注」、按 Enter 或双击选区，打开贴图式浮窗。只需普通截图时，点击「复制」或按 Ctrl+C，复制后返回托盘。
3. 默认「智能选块」模式：悬停选择区域，滚轮切换大小，单击添加批注；直接拖动则手动画框。第一条批注保存后自动展开右侧说明栏。
4. 工具条中的点标注、画框、智能选块、调整分别对应 P / R / B / V。空格或 Alt+左键拖动移动整张贴图；调整模式空白处拖动也可移动贴图。
5. 普通模式滚轮缩放图片，智能模式 Ctrl+滚轮缩放；中键切换原始比例与适应窗口。右键打开保存、复制、重新截图等操作。
6. 导出 JSON 可复制文本，或保存 JSON、原图与批注预览。所有坐标对应原图像素，不受查看缩放影响。
7. 关闭按钮或 Esc 收起贴图，批注保留在内存，托盘右键可恢复。退出程序请使用托盘「退出 Help2Design」；未保存的批注会提示保存。

「保存项目」生成包含原图的 JSON，下次打开可继续编辑。导出窗口也可选择包含原图数据；Base64 用于文件还原，不会自动变成聊天中的图片附件。

贴图截图区与右侧批注栏位于同一窗口，移动窗口时一起移动。当前版本一次编辑一张截图。

## 快捷键

| 快捷键 | 功能 |
| --- | --- |
| Ctrl+Alt+2 / 3 / 4 | 全局区域 / 窗口 / 全屏截图 |
| P / R / B / V | 点标注 / 框选 / 智能选块 / 调整 |
| Ctrl+Enter | 保存批注描述 |
| Ctrl+Z / Ctrl+Y | 撤销 / 重做 |
| Ctrl+O / Ctrl+V | 打开文件 / 粘贴图片 |
| Ctrl+S / Ctrl+E | 保存项目 / 导出 JSON |

快捷键与其他软件冲突时，仍可点击托盘截图。程序以单实例驻留，重复启动会向已有实例请求截图；不会设置开机启动。

## 两种元素识别

**界面元素：Windows UI Automation。** 截图开始时，独立进程读取前方最多五个窗口的可访问性控件树；大约三秒后结束，超时不会卡住编辑器。候选区域可以附带控件名称、类型、AutomationId 与原始屏幕边界。截图裁剪后，选区转为截图内部的坐标，同时保留原边界以及是否被裁剪的信息。

浏览器必须向 Windows 提供元素的可访问性信息，实际效果取决于浏览器、网页和当前窗口；并非每个 DOM 元素都会出现在可访问性树中，也不能据此获取可靠的 CSS selector。被截断的元素能否提供完整边界由提供方决定。没有读到信息时，仍可选窗口、手动框选或使用图像候选。全屏快捷截图直接采集图像，当前不附带 UIA 候选。

**图片区域：本地颜色连通区域 + 边缘分组。** 对缩小后的图像进行颜色量化、连通域、边缘扩张与矩形筛选，之后映射回原图像素。适合卡片、按钮、色块、图片边界及部分文字区域。保留合理的嵌套候选，供用户选择。

这是候选区域检测，不具备人物、动物或具体物体的语义识别能力；复杂照片、渐变、透明叠层可能误选或漏选。第一版选择这种方案是为了离线、快速、没有模型下载；以后可增加可选的视觉模型，输出仍可沿用同一坐标结构。

## JSON 约定

完整规范在 `schema/feedback-v1.schema.json`，采用 JSON Schema Draft 2020-12。`schemaVersion` 当前为 `1.0.0`。

- `capture`：原图尺寸、来源、文件名、SHA-256、时间、可选的屏幕区域和 PNG Base64。
- `annotations`：有序批注数组，每条有稳定 `id`、连续 `number`、`kind`、坐标、`comment`、目标来源及时间。
- 点标注使用 `point: {"x": 120, "y": 80}`，`rectangle` 为 null。
- 框标注使用 `rectangle: {"x1": 40, "y1": 60, "x2": 320, "y2": 200}`，`point` 为 null。
- 原点在原图左上角，单位是原图整数像素；矩形包含左上边界、不包含右下边界。因此宽度为 `x2 - x1`，全图矩形为 `(0, 0) → (width, height)`。
- `target.source` 为 `manual`、`uia` 或 `vision`。`originalScreenBounds` 仅记录原始元素位置；实际批注范围以 `point` / `rectangle` 为准。

缩放贴图不改变导出坐标。保存前会检查空批注、坐标越界、非法矩形、重复 ID 等；导入检查字段和类型、原图哈希与尺寸。项目不包含可执行脚本，也不会请求网络。

## 开发与验证

实现采用 C#、WPF、WinForms、GDI+ 和 Windows UI Automation；运行时只使用系统 .NET Framework 组件。本版没有打包第三方应用或复制 Snipaste / Agentation 的源代码，也没有远端服务。

```powershell
# 使用系统自带 Framework C# 编译器，不需要下载 SDK
.\build.ps1 -Test -UiTest

# 程序自身界面与控件集成测试，测试进程结束后查看结果文件
Start-Process .\bin\Help2Design.Capture.exe -ArgumentList '--ui-test', 'artifacts\ui-test' -Wait

# 可选：独立 JSON Schema 校验，需要 Python 的 jsonschema 包
python tests\validate_exports.py

# 生成便携包
.\package.ps1
```

`Help2Design.Capture.csproj` 同时提供给配有 .NET Framework 4.8 开发组件的 Visual Studio / SDK 环境。

已验证：编译；JSON 中文与转义、数据类型和坐标边界；内嵌原图项目往返与哈希；已知图像卡片检测；负屏幕原点裁剪和被裁剪元素坐标转换；程序自身真实控件的 UIA 读取；批注弹窗保存、右侧删除、撤销重做；浮窗与对话框渲染；无首页启动、取消和托盘恢复；滚轮父子候选链、选区移动与缩放；单实例请求转发。独立 Python 校验器验证了程序实际导出的 JSON。

尚未覆盖真实 Chrome / Edge 网页吸附、不同 DPI 的多显示器实机组合、HDR、受保护视频和提权应用。屏幕采集采用 GDI，当前没有滚动长截图、自由画笔、OCR 或任意物体分割。此版本作为可运行的首版交付，尚未做发行签名或安装器。

异常日志：`%LOCALAPPDATA%\Help2Design\errors.log`。批注和原图保存在用户选定的本地文件中；UIA 临时采集数据在截图完成或取消后清理。
