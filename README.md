# Help2Design Native · 0.5.0

面向 AI 开发反馈的桌面截图批注工具。打开后直接截屏，点击或框选需要修改的位置，输入意见；也可以进入“大爆炸”，移动和缩放截图里的组件，再导出原始位置、目标位置及批注的标准 JSON。

当前开发分支为 `codex/native`，采用 C++20 + Qt 6 Widgets。Windows 与 macOS 分别接入系统截图、快捷键和辅助功能接口；界面和数据处理不依赖浏览器引擎。

| 分支 | 内容 |
| --- | --- |
| `desktop` | 已保留的 Windows WPF 0.2 版本，`cf9c364` |
| `web` | 已保留的 Web 0.3 版本，`66548c5` |
| `codex/native` | 当前 C++ / Qt 桌面版本 |

## 使用

Windows 便携包：`dist/Help2Design-Native-0.5.0-win-x64.zip`。解压完整目录后双击 `Help2Design.exe`，保留同目录的 DLL 和插件文件夹。运行包附带所需依赖，不需要安装 Qt、Python、Node 或 .NET。

首次运行直接进入截图。之后使用 **Ctrl + Shift + 2** 或托盘图标再次截图。快捷键被占用时仍可从托盘操作。点击托盘截图时，程序先收起自身菜单，让系统托盘展开面板失去焦点并完成关闭，再采集画面。

只有截图遮罩置顶。批注窗口和“大爆炸”窗口是普通应用窗口，其他应用可以覆盖它们。

- 移动鼠标智能选块。滚轮向上选更大的区域，向下选更小的区域：**所有已检测到且包含鼠标位置的框都按面积参与切换**，不要求相邻候选互为父子。
- 例如鼠标位于表格的第 3 格，只要识别到单格 3、行 34、区域 3456 和整个表格 123456，它们就都能通过滚轮选中。
- 直接拖动也可截图。确定选区后可以移动选区或拖动八个手柄调整大小。Enter 开始批注，Ctrl+C 直接复制截图，右键返回，Esc 取消。
- 截图后使用智能、点、框、调整四种工具。单击或画框输入文字，右侧同步显示编号和描述。
- 批注的调整模式支持移动标记、拖动框的八个手柄、双击编辑文字。Ctrl+Z 撤销，Ctrl+Y 重做，Delete 删除。
- 拖动顶部栏，或按住空格/Alt 拖动画面，可移动整个批注窗口。Ctrl+滚轮缩放视图；中键切换适应窗口和原尺寸。
- 支持打开、拖入或粘贴 PNG/JPEG/WebP/BMP 图片，以及重新打开项目 JSON。
- Ctrl+S 保存包含原图、批注和布局的项目。关闭窗口后收起到托盘，保留当前内容；退出或替换有修改的项目时提示保存。

Mac 编辑快捷键使用 Command，重做为 Command + Shift + Z；截图快捷键为 Command + Shift + 2。Mac 行为尚待实机验证。

## 大爆炸：直接调整组件布局

点击顶部“大爆炸”，程序按识别框建立可调整区域。小框可以单独操作，大框可以作为组件组整体操作；还可以点击“手动分块”补充区域。

| 操作 | 行为 |
| --- | --- |
| 未选中时，悬停并滚动滚轮 | 遍历包含鼠标位置的全部候选区域 |
| 单击候选区域 | 确认选择组件或组件组 |
| 拖动已选区域内部 | 移动位置 |
| 拖动边缘中点 | 独立改变宽度或高度 |
| 拖动角点 | 保持当前宽高比例缩放，无需按 Shift |
| 选中后滚动滚轮 | 等比例放大、缩小组件或组件组 |
| 修改右侧 X、Y、宽度、高度 | 精确设置画布像素值 |
| 修改右侧“等比缩放” | 按百分比缩放，以本次选中时的尺寸为 100% |
| 方向键 | 移动 1 px |
| 右键、Esc 或“取消选择” | 返回悬停选块 |
| “手动分块”后拖动画框 | 从当前布局中划出新的可操作区域 |
| Ctrl+滚轮 | 只缩放视图，不改变组件尺寸 |

选中单格 1 时只调整 1；选中包含 1234 的区域时，四格整体移动或缩放，内部相对关系随之变化。手动分块可以在组件已经移动、缩放后继续进行。

“大爆炸”内可撤销、重做。点击“完成调整”保存本次布局并返回效果预览；点击“取消”放弃本次进入后的调整。主窗口也可撤销、重做已完成的布局变化。

组件移走后的空位保持透明，界面用棋盘格显示；不补绘复杂背景，也不恢复原图里被遮挡的内容。所有调整限制在原图大小的画布内。切片共用原图像素，大框引用内部切片，不会重复复制同一批原始像素。

原图始终保留。完成后点击“批注原图”添加或修改批注，点击“查看调整效果”切回布局预览；预览上双击可继续调整。**批注仍对应原图位置，布局预览单独表达调整结果。**

## 导出与坐标

“导出 JSON”可直接复制文本，或保存到一个新目录：原图 PNG、带批注的原图预览 PNG、`feedback.json`；有布局时另附 `layout.png` 调整效果图。若文件名与原图冲突，程序会采用另一预览文件名。

开启“包含原图数据”后，单个 JSON 即可重新导入恢复。未开启时，把 JSON 与同目录的原图一起保留或交给 AI。

- 坐标原点是左上角，单位为图像像素，与窗口位置和视图缩放无关。
- 批注点使用 `point: {x, y}`；批注框使用 `rectangle: {x1, y1, x2, y2}`。
- 右下边界不包含在框内，宽度等于 `x2 - x1`，高度等于 `y2 - y1`。
- `capture.sha256` 始终标识原始 PNG。未内嵌原图时，重新导入需要同目录的 `capture.imageFile`。
- Windows 的 `screenBounds` 和 `originalScreenBounds` 是系统物理屏幕坐标，可以为负。Mac 的系统坐标采用逻辑点，当前不混写到物理屏幕坐标字段，故这两个字段为空；图像像素坐标完整保留。
- 无布局时继续导出 [v1.0](schema/feedback-v1.schema.json)，包含 Mac 辅助功能来源时为 [v1.1](schema/feedback-v1.1.schema.json)。
- 有“大爆炸”布局时导出 [v2.0](schema/feedback-v2.schema.json)。`layout.pieces` 记录每个切片的 `source` 原图范围与 `destination` 目标范围；允许小数坐标。目标坐标使用与原图同宽高的固定画布，空位背景为透明。
- `layout.groups` 用 `pieceIds` 表达组件组。识别区域保留 `originalRectangle`，在当前布局中手工建立的区域该字段为空。按切片数组顺序绘制可以重现叠放效果。
- Native 0.5.0 可以打开旧桌面版和 Web 版的 v1 项目，以及 v1.1、v2 项目。旧应用不支持 v2 布局，不能用旧应用恢复新布局。
- 导入检查字段类型、唯一 ID、连续批注编号、图片哈希、实际尺寸和坐标范围；布局额外检查源切片完整覆盖且不重叠、组件组引用有效。JSON Schema 与业务校验共同约束数据。

识别得到的是视觉位置或系统辅助功能信息，不包含代码仓库中的 DOM、组件名或源码位置；网页 DOM 标注工具仍是独立产品方向。

## 识别方式与边界

Windows 通过 UI Automation、Mac 通过 Accessibility 获取目标应用公开的元素边界。截图前的元素探测在独立短进程中运行，超时会停止，避免目标应用阻塞截图界面。

图片识别完全在本机运行，使用颜色连通区域和边缘聚合。它能找到卡片、图片区域和较明确的轮廓，但不是 OCR 或物体语义识别，无法保证每个候选框都是用户理解的组件。全部包含框都能参与选择；未识别到的范围可以手动框选。无需网络服务、账号或模型下载。

当前支持从多块屏幕中选择其中一块内的区域，不支持跨显示器拼接选区。混合缩放、多屏布局、受保护画面和不同浏览器的系统元素暴露情况仍需更多设备测试。单图最多 3200 万像素、单边不超过 32767，最多 1000 条批注，每条 10000 字；布局最多 512 个组件组、8192 个原图切片。

## 构建

依赖：Qt **6.8.3**（qtbase、qtimageformats，动态库）、CMake 3.24+、Ninja、C++20 编译器。
Windows 使用 MinGW GCC 13.1.0；Mac 使用 Xcode Command Line Tools 和匹配的 Qt SDK。

Windows PowerShell 7 示例，CMake 在 PATH 中：

```powershell
./scripts/build-windows.ps1 -QtRoot C:/Qt/6.8.3/mingw_64 -Compiler C:/Qt/Tools/mingw1310_64/bin/g++.exe -Ninja C:/Tools/ninja.exe
./scripts/package-windows.ps1 -QtRoot C:/Qt/6.8.3/mingw_64 -CompilerBin C:/Qt/Tools/mingw1310_64/bin
```

打包脚本使用新的输出目录，避免覆盖已有成果；重复打包可传入新的 `-OutputDirectory`。

Mac（当前脚本未经本机执行）：

```bash
export QT_ROOT="$HOME/Qt/6.8.3/macos"
bash scripts/build-macos.sh
```

脚本配置为生成通用 .app 和供本地测试的 .dmg，使用临时签名；这不是已经签名公证的公开发行版。
