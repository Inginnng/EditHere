# EditHere Brand Assets

Master vector logo and wordmark assets (precision viewfinder + anodized obsidian squircle + geometric Manrope wordmark with cobalt focal tittle):

- `edithere-wordmark.svg` — Dark monochrome wordmark (`#111318`) with `#007AFF` cobalt precision tittle (`2288x512`, `viewBox="0 0 572 128"`), for light surfaces.
- `edithere-wordmark-light.svg` — Light monochrome wordmark (`#F4F6FA`) with `#0A84FF` cobalt precision tittle (`2288x512`, `viewBox="0 0 572 128"`), for dark surfaces.
- `edithere-lockup.svg` — Obsidian squircle icon + dark wordmark (`2888x512`, `viewBox="0 0 722 128"`), for light surfaces.
- `edithere-lockup-light.svg` — Obsidian squircle icon + light wordmark (`2888x512`, `viewBox="0 0 722 128"`), for dark surfaces.

Related app icon sources in `assets/icons/`:
- `assets/icons/edithere.svg` — Unplated viewfinder & cobalt focal core symbol (`64x64`), safe on both light and dark surfaces.
- `assets/icons/edithere-macos.svg` — Anodized obsidian squircle icon (`1024x1024`) used for macOS, Windows PNG/ICO, frontend navbar, and connector metadata.

Notes:
- Vector letterforms are derived from [Manrope](https://fonts.google.com/specimen/Manrope) (SIL Open Font License 1.1; see `Manrope-OFL.txt`) and stored as vector `<path>` outlines so rendering never depends on system font installation.
- Brand name is strictly `EditHere`. Do not re-add gradients across body glyphs or cartoon pencil props.
